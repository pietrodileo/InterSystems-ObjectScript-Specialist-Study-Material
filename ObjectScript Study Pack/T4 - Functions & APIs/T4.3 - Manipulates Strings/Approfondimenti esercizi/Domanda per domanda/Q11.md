# T4.3 · Q11 — Normalizzazione del caso

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-11-single>)

## Il passaggio che risolve l’esercizio

ZCONVERT con U produce maiuscolo nel contesto previsto.

## Che cosa insegna in più

Una rappresentazione normalizzata aiuta confronti coerenti, ma non sostituisce le regole di collazione né conserva la grafia originale.

## Prova a cambiare il caso

Se devi ristampare il nome esattamente come inserito, basta conservarne solo il maiuscolo?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 3; Further insights, panel 3. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are normalizing user input for case-insensitive comparison. Consider:

set input = "Hello World"
write $ZCONVERT(input, "U")

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-11-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** HELLO WORLD

$ZCONVERT with "U" converts a string to uppercase. Other options: "L" for lowercase, "W" for title case (capitalize first letter of each word). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fzconvert))

</details>
