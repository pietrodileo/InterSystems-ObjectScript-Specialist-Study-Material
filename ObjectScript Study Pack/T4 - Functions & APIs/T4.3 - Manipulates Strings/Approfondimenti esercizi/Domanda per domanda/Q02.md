# T4.3 · Q02 — Aggiornamento di un campo delimitato

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-2-single>)

## Il passaggio che risolve l’esercizio

SET $PIECE sostituisce il terzo campo New York con Boston e conserva gli altri campi.

## Che cosa insegna in più

Cambiare un campo delimitato è diverso da sostituire tutte le occorrenze di una parola nel record.

## Prova a cambiare il caso

Se New York compare anche in un altro campo, questa operazione lo modifica?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A data correction routine needs to update the city field in a delimited record. Consider:

set rec = "Smith^John^New York^NY"
set $PIECE(rec, "^", 3) = "Boston"
write rec

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-2-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** Smith^John^Boston^NY

SET $PIECE can modify a string by replacing a specific delimited piece. Setting $PIECE(rec, "^", 3\) \= "Boston" replaces the third ^-delimited piece ("New York") with "Boston", resulting in "Smith^John^Boston^NY". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fpiece))

</details>
