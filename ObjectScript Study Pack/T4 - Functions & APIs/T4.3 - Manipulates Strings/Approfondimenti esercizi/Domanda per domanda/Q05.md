# T4.3 · Q05 — Sostituzione di un intervallo di caratteri

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

I caratteri C e D nelle posizioni 3..4 diventano X e Y: ABXYEF.

## Che cosa insegna in più

L’uguaglianza di lunghezza mantiene le posizioni successive nell’esempio. Una sostituzione di lunghezza diversa richiede attenzione al layout risultante.

## Prova a cambiare il caso

Questo comando sta selezionando il terzo e quarto campo separato da virgole?

<details>
<summary>Ragionamento e risposta</summary>

No, seleziona caratteri.

</details>

## Testo dell’esercizio

```text
You need to replace characters in a fixed-width string. Consider:

set code = "ABCDEF"
set $EXTRACT(code, 3, 4) = "XY"
write code

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** ABXYEF

SET $EXTRACT(str, from, to) \= value replaces characters at positions from through to with value. Positions 3-4 ("CD") are replaced by "XY", giving "ABXYEF". The replacement length matches the range. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fextract))

</details>
