# T4.3 · Q13 — Addizione tollerante

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-13-single>)

## Il passaggio che risolve l’esercizio

3cats e 5dogs diventano 3 e 5 nel contesto aritmetico: risultato otto.

## Che cosa insegna in più

Questo comportamento può nascondere unità incompatibili. Il linguaggio non verifica che il significato delle quantità sia compatibile.

## Prova a cambiare il caso

Sommare 3kg e 5m con + produce un errore di unità?

<details>
<summary>Ragionamento e risposta</summary>

No: occorre validare il dominio nell’applicazione.

</details>

## Testo dell’esercizio

```text
You encounter a puzzling expression in legacy code. Consider:

set x = "3cats"
set y = "5dogs"
write x + y

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-13-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 8

The \+ operator performs numeric addition in ObjectScript. Strings are coerced to numbers by extracting the leading numeric portion: "3cats" becomes 3, "5dogs" becomes 5\. So 3 \+ 5 \= 8\. String concatenation uses the \_ operator: "3cats" \_ "5dogs" \= "3cats5dogs". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators#GCOS_operators_numeric))

</details>
