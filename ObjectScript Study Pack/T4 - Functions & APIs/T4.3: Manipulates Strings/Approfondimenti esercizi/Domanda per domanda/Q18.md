# T4.3 · Q18 — Sottostringa contro singoli caratteri

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-18-single>)

## Il passaggio che risolve l’esercizio

REPLACE trasforma i due an in X e dà bXXa; TRANSLATE mappa ogni a in X e n in Y, dando bXYXYX.

## Che cosa insegna in più

Rappresenta prima le unità su cui lavora la funzione: coppie di caratteri per REPLACE, caratteri indipendenti per TRANSLATE.

## Prova a cambiare il caso

TRANSLATE con from=an cerca la sequenza an intera?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
You need to understand the difference between $REPLACE and $TRANSLATE. Consider:

set str = "banana"
set r1 = $REPLACE(str, "an", "X")
set r2 = $TRANSLATE(str, "an", "XY")
write r1, " / ", r2

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-18-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** bXXa / bXYXYX

$REPLACE works on substrings: it finds "an" in "banana" and replaces each occurrence. "b-an-an-a" has two occurrences of "an", giving "bXXa". $TRANSLATE works character-by-character: 'a' maps to 'X' (pos 1-\>pos 1\) and 'n' maps to 'Y' (pos 2-\>pos 2). So in "banana": b stays, a-\>X, n-\>Y, a-\>X, n-\>Y, a-\>X \= "bXYXYX". This illustrates the fundamental difference: $REPLACE matches substrings, $TRANSLATE maps individual characters. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_freplace))

</details>
