# T4.3 · Q06 — REPLACE e reinserimento dei risultati

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-6-single>)

## Il passaggio che risolve l’esercizio

Ogni chiamata produce la stringa trasformata, che viene riassegnata a result prima della sostituzione successiva.

## Che cosa insegna in più

L’ordine delle sostituzioni conta se il testo inserito contiene un altro segnaposto. Un template semplice non gestisce automaticamente escaping o contenuti annidati.

## Prova a cambiare il caso

Chiamare REPLACE senza conservare il risultato cambia template in posto?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A template engine needs to replace placeholders. Consider:

set template = "Hello {{name}}, welcome to {{city}}!"
set result = $REPLACE(template, "{{name}}", "Alice")
set result = $REPLACE(result, "{{city}}", "Paris")
write result

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** Hello Alice, welcome to Paris!

$REPLACE replaces all occurrences of a substring with a replacement. The first call replaces {{name}} with Alice, the second replaces {{city}} with Paris. Each call returns a new string; the original is not modified in place (the result is reassigned). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_freplace))

</details>
