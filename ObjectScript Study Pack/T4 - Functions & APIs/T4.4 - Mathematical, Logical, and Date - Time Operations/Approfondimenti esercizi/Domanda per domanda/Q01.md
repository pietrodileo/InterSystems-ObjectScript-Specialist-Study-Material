# T4.4 · Q01 — Il simbolo decide l’operazione

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-1-single>)

## Il passaggio che risolve l’esercizio

A+B usa conversione numerica e produce zero; la concatenazione richiede underscore.

## Che cosa insegna in più

Non dedurre l’operazione dal contenuto testuale. Questa tolleranza rende particolarmente importante validare un dato atteso come numero.

## Prova a cambiare il caso

A_B e A+B devono avere lo stesso risultato se entrambi sono stringhe?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
Which of the following is the result of this expression:

"A" + "B"
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-1-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: E.** 0

In ObjectScript, the \+ operator always performs numeric addition. Non-numeric strings like "A" and "B" are coerced to 0 (they have no leading numeric portion). So "A" \+ "B" \= 0 \+ 0 \= 0\. String concatenation uses the \_ operator: "A" \_ "B" \= "AB". No error is thrown because weak typing is a core feature of ObjectScript. (Reference: InterSystems Practice Q16; [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators#GCOS_operators_numeric))

</details>
