# T4.4 · Q06 — Resto con operando negativo

## Il passaggio che risolve l’esercizio

Il caso -7#3 restituisce 2 secondo la semantica del resto ObjectScript.

## Che cosa insegna in più

Non trasferire automaticamente il risultato dell’operatore percentuale di un altro linguaggio. Verifica anche il segno del divisore quando generalizzi.

## Testo dell’esercizio

```text
You encounter the ObjectScript modulo operator with a negative number. Consider:

write -7 # 3

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 2

In ObjectScript, the modulo operator (#) always returns a result with the same sign as the divisor (or zero). For -7 \# 3: the result is 2 (because -7 \= -3\*3 \+ 2). This differs from languages like C where -7 % 3 \= -1. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators#GCOS_operators_numeric))

</details>
