# T4.7 · Q03 — Lettura a blocchi o per righe

## Il passaggio che risolve l’esercizio

Il loop continua finché AtEnd non segnala la fine e legge il prossimo contenuto.

## Che cosa insegna in più

Il confine di un blocco Read non è necessariamente una riga; scegli ReadLine quando il formato di elaborazione è per righe, considerando anche gli errori di lettura.

## Testo dell’esercizio

```text
while 'stream.AtEnd {

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** ```text
while 'stream.AtEnd {
  set line = stream.ReadLine()
  write line, !
}
```

The standard stream reading pattern uses While 'stream.AtEnd (while NOT at end) with ReadLine() or Read(). AtEnd is a property that returns 1 when the stream position has reached the end. HasNext(), Next(), ReadChar(), and GetAll() are not standard stream methods. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_propstream))

</details>
