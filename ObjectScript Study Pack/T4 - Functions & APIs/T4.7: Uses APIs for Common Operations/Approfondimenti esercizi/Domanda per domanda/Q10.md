# T4.7 · Q10 — Dichiarazione Content-Type e contenuto reale

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-10-single>)

## Il passaggio che risolve l’esercizio

EntityBody contiene il testo JSON e ContentType ne dichiara il formato al destinatario.

## Che cosa insegna in più

L’header non rende valido un corpo malformato. Costruire JSON con una serializzazione appropriata evita errori di quoting e tipi.

## Prova a cambiare il caso

Scrivere testo arbitrario e dichiararlo application/json lo converte automaticamente?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
You are building an integration that sends JSON data via HTTP POST. Consider:

set req = ##class(%Net.HttpRequest).%New()
set req.Server = "api.example.com"
set req.ContentType = "application/json"
do req.EntityBody.Write("{""name"":""John""}")
set sc = req.Post("/users")

Which statement best describes what this code does?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-10-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** It sends a POST request with a JSON body to /users

The code creates an HTTP POST request with Content-Type set to application/json. The request body is written to req.EntityBody (a stream). Post("/users") sends the request with the JSON body to the /users endpoint. EntityBody is the standard way to set the request body for POST/PUT requests. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GNET_http))

</details>
