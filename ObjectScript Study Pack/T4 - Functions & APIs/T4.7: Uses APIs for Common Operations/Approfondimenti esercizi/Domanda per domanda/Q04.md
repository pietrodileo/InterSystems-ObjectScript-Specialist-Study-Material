# T4.7 · Q04 — Rewind modifica il cursore

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-4-single>)

## Il passaggio che risolve l’esercizio

Rewind riporta la posizione di lettura all’inizio senza cancellare i dati.

## Che cosa insegna in più

Separare contenuto e posizione spiega perché una seconda scansione può essere vuota prima di rewind e identica dopo.

## Prova a cambiare il caso

Rewind svuota il file o il global che contiene il flusso?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A colleague's code reads a stream but needs to read it again from the beginning. Consider:

set stream = ##class(%Stream.GlobalCharacter).%New()
do stream.Write("First line")
do stream.WriteLine("")
do stream.Write("Second line")
// Read the stream once...
while 'stream.AtEnd { set x = stream.Read() }
// Now need to read it again

What method resets the read position to the beginning?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-4-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** do stream.Rewind()

Rewind() resets the stream's read position to the beginning, allowing you to read the content from the start again. It does not modify the stream's content. There is no Reset(), Position property, or MoveToStart() method on standard streams. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_propstream))

</details>
