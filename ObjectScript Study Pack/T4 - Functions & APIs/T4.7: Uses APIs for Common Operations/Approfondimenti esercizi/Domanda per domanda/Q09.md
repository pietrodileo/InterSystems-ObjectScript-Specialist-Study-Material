# T4.7 · Q09 — Corpo come stream ed esito come livelli distinti

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-9-single>)

## Il passaggio che risolve l’esercizio

HttpResponse.Data è il flusso del corpo; StatusCode è il codice HTTP della risposta.

## Che cosa insegna in più

Prima controlla il risultato della richiesta, poi il codice HTTP, infine il formato del corpo. Uno status di trasporto positivo non implica risposta applicativa 200.

## Prova a cambiare il caso

Se il server risponde 404 con JSON di errore, puoi trattare il corpo come elenco utenti riuscito?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
After making an HTTP request, you need to read the response body. Consider:

set req = ##class(%Net.HttpRequest).%New()
set req.Server = "api.example.com"
set sc = req.Get("/users")

How do you access the response body?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-9-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** set body \= req.HttpResponse.Data

After an HTTP request, the response is in req.HttpResponse (a %Net.HttpResponse object). The response body is available as a stream in req.HttpResponse.Data. You can read it with .Read() or iterate with ReadLine(). The status code is in req.HttpResponse.StatusCode. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GNET_http))

</details>
