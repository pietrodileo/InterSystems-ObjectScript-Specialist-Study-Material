# T4.5 · Q06 — Controllo prima dell’effetto

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-6-single>)

## Il passaggio che risolve l’esercizio

QUIT quando i=3 precede WRITE: quindi tre non viene stampato e il programma continua dopo il ciclo.

## Che cosa insegna in più

La posizione del controllo cambia il risultato. Fermarsi prima o dopo l’effetto distingue visita esclusiva e inclusiva del valore limite.

## Prova a cambiare il caso

Spostando QUIT dopo WRITE, apparirebbe anche tre?

<details>
<summary>Ragionamento e risposta</summary>

Sì nello stesso schema di ciclo.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are tracing the execution of a loop with a post-conditional quit. Consider:

for i = 1:1:5 {
  quit:i=3
  write i, " "
}
write "done"

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** 1 2 done

The loop writes 1 (i\=1), then writes 2 (i\=2). When i\=3, the post-conditional Quit:i\=3 is true, so QUIT exits the For loop before the Write. Execution continues after the loop with Write "done". Output: "1 2 done". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_cquit))

</details>
