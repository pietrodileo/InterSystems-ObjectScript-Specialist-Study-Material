# T4.5 · Q04 — Copertura del confine x=5

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-4-single>)

## Il passaggio che risolve l’esercizio

Con dieci viene scritto big e la seconda assegnazione è saltata.

## Che cosa insegna in più

Le condizioni x>5 e x<5 lasciano scoperto il valore cinque. Il codice può stampare un vecchio risultato o incontrare un indefinito.

## Prova a cambiare il caso

Cosa assegna a result quando x=5?

<details>
<summary>Ragionamento e risposta</summary>

Nulla da queste due righe; serve un ramo o un default esplicito.

</details>

Visual connection: Core mechanisms, panel 3; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are categorizing values using post-conditionals. Consider:

set x = 10
set:x>5 result = "big"
set:x<5 result = "small"
write result

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-4-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** big

x\=10. The first post-conditional x\>5 is true, so result is set to "big". The second post-conditional x\<5 is false (10 is not less than 5), so that SET is skipped. Write outputs "big". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_commands#GCOS_commands_postconditional))

</details>
