# T4.5 · Q10 — Test booleano non validante

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-10-single>)

## Il passaggio che risolve l’esercizio

3.5abc viene interpretato come nonzero e produce TRUE.

## Che cosa insegna in più

Un valore vero non è necessariamente un numero scritto nel formato che la funzione richiede. Validazione e scelta del ramo sono due operazioni distinte.

## Prova a cambiare il caso

TRUE dimostra che il suffisso abc sia ammesso dal dominio?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You encounter a value with mixed numeric and string content in a Boolean context. Consider:

set val = "3.5abc"
if val {
  write "TRUE"
} else {
  write "FALSE"
}

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-10-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** TRUE

ObjectScript converts "3.5abc" to numeric by extracting the leading numeric portion: 3.5. Since 3.5 is non-zero, the Boolean evaluation is true. This is consistent with the weak typing rules used everywhere in ObjectScript. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators#GCOS_operators_boolean))

</details>
