# T4.5 · Q13 — Selezione totale oppure errore esplicito

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-13-single>)

## Il passaggio che risolve l’esercizio

Nessuna condizione è vera e SELECT genera l’errore previsto.

## Che cosa insegna in più

Un default evita l’errore solo se il dominio prevede un valore per il caso restante. In altri casi l’errore può segnalare correttamente uno stato inatteso.

## Prova a cambiare il caso

Aggiungere sempre Unknown può nascondere una condizione impossibile che vorresti rilevare?

<details>
<summary>Ragionamento e risposta</summary>

Sì.

</details>

## Testo dell’esercizio

```text
A developer forgot the default case in $SELECT. Consider:

write $SELECT(0:"A", 0:"B")

What happens?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-13-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** Throws a \<SELECT\> error

If no condition in $SELECT evaluates to true, ObjectScript throws a \<SELECT\> error. Always include a default case using 1:defaultValue as the last condition to prevent this error. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fselect))

</details>
