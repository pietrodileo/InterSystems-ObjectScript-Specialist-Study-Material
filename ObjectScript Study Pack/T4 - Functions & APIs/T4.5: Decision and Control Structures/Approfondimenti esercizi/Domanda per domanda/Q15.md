# T4.5 · Q15 — QUIT con valore nel contesto sbagliato

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-15-single>)

## Il passaggio che risolve l’esercizio

Il frammento usa QUIT i dentro FOR, dove non è l’uscita con risultato prevista: per tornare dal metodo usa RETURN i.

## Che cosa insegna in più

Lo stesso nome di comando non ha un significato indipendente dal contesto di esecuzione. Leggi anche i blocchi circostanti.

## Prova a cambiare il caso

Per restituire la posizione due e saltare il return -1 finale, cosa usi?

<details>
<summary>Ragionamento e risposta</summary>

RETURN 2 nel punto della corrispondenza.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are debugging a loop that uses QUIT incorrectly. Consider:

ClassMethod FindItem(list As %ListOfDataTypes, target As %String) As %Integer
{
  for i = 1:1:list.Count() {
    if list.GetAt(i) = target {
      quit i
    }
  }
  return -1
}

Assuming the target is found at position 2, what does this method return?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-15-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: D.** A \<COMMAND\> error

QUIT with an argument (QUIT i) is not allowed inside a FOR block \-- it produces a \<COMMAND\> error. Inside a FOR loop, QUIT (without an argument) exits the loop, while QUIT expr is only valid for exiting a method with a return value. To return from the method, use RETURN i instead of QUIT i. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_cquit))

</details>
