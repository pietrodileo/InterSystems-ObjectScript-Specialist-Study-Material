# T4.5 · Q07 — Postcondizionali indipendenti

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-7-single>)

## Il passaggio che risolve l’esercizio

Viene eseguito soltanto WRITE con status active; l’altro comando resta saltato.

## Che cosa insegna in più

Due postcondizionali non creano necessariamente un ramo esaustivo. Un terzo stato può non produrre alcuna uscita.

## Prova a cambiare il caso

Con status pending compare automaticamente Offline?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are using post-conditionals with the Write command. Consider:

set status = "active"
write:status="active" "Online"
write:status="inactive" "Offline"

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-7-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** Online

Post-conditionals work with Write and most other commands. Write:status\="active" executes because the condition is true. Write:status\="inactive" is skipped because the condition is false. Only "Online" is output. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_commands#GCOS_commands_postconditional))

</details>
