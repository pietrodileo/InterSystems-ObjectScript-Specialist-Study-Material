# T4.5 · Q05 — Uscita dal metodo

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

RETURN found al secondo giro termina Process; il return finale non viene raggiunto.

## Che cosa insegna in più

Un risultato può essere stabilito dentro un ciclo ma appartenere al metodo intero. Scegli il comando di uscita in base a quel confine.

## Prova a cambiare il caso

Sostituendo con un QUIT semplice, il metodo salta anche il return finale?

<details>
<summary>Ragionamento e risposta</summary>

No, nel contesto mostrato esce dal ciclo.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You need to understand the difference between QUIT and RETURN. Consider:

ClassMethod Process() As %String
{
  for i = 1:1:3 {
    if i = 2 return "found"
  }
  return "not found"
}

What does ..Process() return?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** "found"

RETURN exits the entire method immediately, regardless of how many nested loops or blocks surround it. When i\=2, RETURN "found" exits the method and returns "found". If QUIT were used instead, it would only exit the for loop, and execution would continue to RETURN "not found". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_creturn))

</details>
