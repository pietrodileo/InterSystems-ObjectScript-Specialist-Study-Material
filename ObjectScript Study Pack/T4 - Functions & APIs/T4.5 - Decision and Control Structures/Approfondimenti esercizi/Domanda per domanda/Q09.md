# T4.5 · Q09 — Saltare una iterazione

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-9-single>)

## Il passaggio che risolve l’esercizio

CONTINUE sugli i pari evita il resto del corpo; solo 1,3,5,7,9 incrementano count.

## Che cosa insegna in più

Non esce dal ciclo intero. Spostare count prima di CONTINUE cambierebbe la misura che stai facendo.

## Prova a cambiare il caso

Con count prima della condizione otterresti ancora cinque?

<details>
<summary>Ragionamento e risposta</summary>

No, conteresti anche le iterazioni poi saltate.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are counting odd numbers using Continue with a post-conditional. Consider:

set count = 0
for i = 1:1:10 {
  continue:i#2=0
  set count = count + 1
}
write count

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-9-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** 5

Continue:i#2\=0 skips the rest of the loop body when i is even (i modulo 2 equals 0). So count is incremented only for odd values of i: 1, 3, 5, 7, 9 \= 5 times. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_ccontinue))

</details>
