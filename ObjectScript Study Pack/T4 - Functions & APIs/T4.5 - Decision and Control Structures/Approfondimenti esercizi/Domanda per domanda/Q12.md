# T4.5 · Q12 — Prima condizione vera

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-12-single>)

## Il passaggio che risolve l’esercizio

SELECT sceglie il ramo cat e restituisce Meow; il default finale copre gli altri casi.

## Che cosa insegna in più

L’ordine conta se più condizioni possono essere vere: il primo ramo soddisfatto determina il valore.

## Prova a cambiare il caso

Se un primo ramo 1:Unknown fosse messo all’inizio, raggiungeresti ancora Meow?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 3; Further insights, panel 3. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are using $SELECT for a compact conditional. Consider:

set x = "cat"
write $SELECT(x="dog":"Woof", x="cat":"Meow", 1:"Unknown")

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-12-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Meow

$SELECT evaluates conditions left to right and returns the value associated with the first true condition. x\="dog" is false, x\="cat" is true, so it returns "Meow". The 1:"Unknown" acts as a default case (1 is always true). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fselect))

</details>
