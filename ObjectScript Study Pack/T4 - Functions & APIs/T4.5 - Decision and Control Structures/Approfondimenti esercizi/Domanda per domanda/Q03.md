# T4.5 · Q03 — Valori diversi, stesso ramo falso

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-3-multiple>)

## Il passaggio che risolve l’esercizio

Stringa vuota, zero e testi che si convertono a zero arrivano tutti al ramo falso.

## Che cosa insegna in più

Un ramo condiviso non rende i dati equivalenti: potresti aver bisogno di distinguere assenza, zero valido e input malformato.

## Prova a cambiare il caso

Un conteggio zero e un campo mancante devono essere trattati sempre nello stesso modo?

<details>
<summary>Ragionamento e risposta</summary>

Dipende dal contratto, non dall’IF numerico.

</details>

## Testo dell’esercizio

```text

You are auditing code for Boolean logic bugs. Which of the following ObjectScript values evaluate to FALSE (0)? (Select all that apply)

**A.** "" (empty string)

**B.** 0

**C.** "0"

**D.** "abc"

**E.** "0.0"

**F.** 1

### Answer and explanation

**Correct answer: A.** "" (empty string)

**Correct answer: B.** 0

**Correct answer: C.** "0"

**Correct answer: D.** "abc"

**Correct answer: E.** "0.0"

All are false except 1\. Empty string, 0, "0", and "0.0" are all numerically zero. "abc" has no leading digits, so it converts to 0 (false). Only non-zero numeric values (like 1, -5, 3.14, "2dogs") are true. This is a critical concept for post-conditionals. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators#GCOS_operators_boolean))

```
