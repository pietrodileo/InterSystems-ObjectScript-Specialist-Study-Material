# T4.6 · Q11 — Catena primaria transitiva

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-11-single>)

## Il passaggio che risolve l’esercizio

Employee deriva da Person, che deriva da Entity e Persistent: nell’esempio tutti i test riportati risultano veri.

## Che cosa insegna in più

La transitività della catena non va confusa con la presenza di qualunque superclass secondaria in una gerarchia multipla.

## Prova a cambiare il caso

Aggiungere un mixin secondario autorizza a generalizzare lo stesso test senza consultarne il contratto?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A class hierarchy has three levels. Consider:

Class Base.Entity Extends %Persistent { }
Class App.Person Extends Base.Entity { }
Class App.Employee Extends App.Person { }

set emp = ##class(App.Employee).%New()
write emp.%IsA("Base.Entity"), " "
write emp.%IsA("App.Person"), " "
write emp.%IsA("%Library.Persistent")

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-11-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** 1 1 1

%IsA checks the entire inheritance chain. App.Employee extends App.Person, which extends Base.Entity, which extends %Persistent (which is %Library.Persistent). So the Employee object %IsA all of these classes, returning 1 for each check. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_misa))

</details>
