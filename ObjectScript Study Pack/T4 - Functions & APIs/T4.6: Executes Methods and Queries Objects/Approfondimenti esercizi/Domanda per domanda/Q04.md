# T4.6 · Q04 — Dispatch dinamico d’istanza

## Il passaggio che risolve l’esercizio

METHOD chiama Add sull’oref ricevuto e restituisce 30 per 10 e 20.

## Che cosa insegna in più

Serve un riferimento valido e un metodo compatibile con gli argomenti. La chiamata dinamica non verifica da sola la semantica dei dati.

## Prova a cambiare il caso

Un oggetto senza Add viene reso compatibile solo perché il nome è una variabile?

<details>
<summary>Ragionamento e risposta</summary>

No.

## Testo dell’esercizio

```text
You need to dynamically invoke an instance method. Consider:

set obj = ##class(App.Calculator).%New()
set methodName = "Add"
set result = $METHOD(obj, methodName, 10, 20)
write result

Assuming Add returns the sum of its arguments, what is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-4-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** 30

$METHOD dynamically invokes an instance method by name. $METHOD(obj, "Add", 10, 20\) is equivalent to obj.Add(10, 20). Since Add returns the sum, the result is 30\. This is useful when the method name is determined at runtime (e.g., from configuration). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fmethod))

</details>
