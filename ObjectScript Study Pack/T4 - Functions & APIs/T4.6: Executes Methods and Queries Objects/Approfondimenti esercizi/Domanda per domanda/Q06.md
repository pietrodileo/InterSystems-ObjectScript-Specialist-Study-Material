# T4.6 · Q06 — Validità dell’oref prima del tipo

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-6-single>)

## Il passaggio che risolve l’esercizio

ISOBJECT distingue il testo Hello da un riferimento valido a un’istanza.

## Che cosa insegna in più

Un testo che assomiglia alla stampa di un oref non diventa un riferimento. Non ricostruire oggetti concatenando numeri e nomi.

## Prova a cambiare il caso

ISOBJECT=1 dimostra anche che sia una classe Patient?

No, è una verifica successiva distinta.

## Testo dell’esercizio

```text
You are validating input and need to check if a variable holds an object reference. Consider:

set x = "Hello"
set y = ##class(%ArrayOfDataTypes).%New()
write $ISOBJECT(x), " ", $ISOBJECT(y)

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 0 1

$ISOBJECT returns 1 if the variable contains a valid object reference (OREF) and 0 otherwise. "Hello" is a string, not an OREF, so $ISOBJECT returns 0\. The %ArrayOfDataTypes instance is a valid OREF, so $ISOBJECT returns 1\. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fisobject))

</details>
