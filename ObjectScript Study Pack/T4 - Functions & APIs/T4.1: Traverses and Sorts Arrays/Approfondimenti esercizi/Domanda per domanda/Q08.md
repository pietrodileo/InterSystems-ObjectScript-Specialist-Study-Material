# T4.1 · Q08 — Zero è una chiave valida

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-8-single>)

## Il passaggio che risolve l’esercizio

I numeri vengono visitati come -3,-1,0,2. Il valore numerico zero non è il segnale di fine usato dal loop.

## Che cosa insegna in più

Un controllo IF key può fermarsi erroneamente a zero. Confronta esplicitamente con il sentinel stringa vuota previsto.

## Prova a cambiare il caso

Un loop che termina quando key è numericamente falso visita sempre arr(0)?

<details>
<summary>Ragionamento e risposta</summary>

No: può confondere una chiave valida con la fine.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
While investigating a bug, you examine an array that uses negative subscripts:

set arr(-3) = "X"
set arr(0) = "Y"
set arr(2) = "Z"
set arr(-1) = "W"
set key = ""
for {
  set key = $ORDER(arr(key))
  quit:key=""
  write key, " "
}

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-8-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** -3 -1 0 2

Numeric subscripts are sorted in numeric order, including negative numbers. The traversal order is -3, -1, 0, 2\. Canonical numeric sorting respects the actual numeric value. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_variables#GCOS_variables_global_subscripts))

</details>
