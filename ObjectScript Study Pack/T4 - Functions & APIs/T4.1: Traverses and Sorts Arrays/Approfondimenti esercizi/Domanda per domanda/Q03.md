# T4.1 · Q03 — Numero e codice alfanumerico

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-3-single>)

## Il passaggio che risolve l’esercizio

1,3,10 sono chiavi numeriche; 10A e 2B sono stringhe confrontate secondo la collazione dello scenario.

## Che cosa insegna in più

Il prefisso numerico usato in un’addizione non trasforma automaticamente un identificatore alfanumerico in un subscript numerico.

## Prova a cambiare il caso

2B deve stare prima di 10 perché comincia con 2?

<details>
<summary>Ragionamento e risposta</summary>

No: appartiene al gruppo delle stringhe.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer is loading patient records into a local array and notices the traversal order is unexpected. Consider:

set patients(3) = "Chen"
set patients("10A") = "Patel"
set patients(1) = "Smith"
set patients(10) = "Jones"
set patients("2B") = "Garcia"

What is the $ORDER traversal order of the subscripts?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-3-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** 1, 3, 10, "10A", "2B"

Canonical ordering places numeric subscripts first (sorted numerically: 1, 3, 10), then string subscripts (sorted by ASCII collation: "10A" before "2B" because "1" \< "2" in ASCII). "10A" and "2B" are strings because they contain non-numeric characters. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_variables#GCOS_variables_global_subscripts))

</details>
