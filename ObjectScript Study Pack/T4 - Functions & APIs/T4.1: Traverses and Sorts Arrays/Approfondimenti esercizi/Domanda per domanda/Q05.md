# T4.1 · Q05 — Separare chiave visitata e valore stampato

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

L’ordine 1,2,3,10 produce i valori A,D,B,C: la stampa è ADBC.

## Che cosa insegna in più

Per risolvere un loop scrivi prima la sequenza delle chiavi e poi sostituisci ciascuna con il suo valore. Non ordinare direttamente le lettere.

## Prova a cambiare il caso

Scambiando i valori di 2 e 10, cambiano le chiavi visitate?

<details>
<summary>Ragionamento e risposta</summary>

No, cambia soltanto il testo prodotto.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A colleague asks you to review their array traversal code. Consider:

set arr(1) = "A"
set arr(3) = "B"
set arr(10) = "C"
set arr(2) = "D"
set key = ""
for {
  set key = $ORDER(arr(key))
  quit:key=""
  write arr(key)
}

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** ADBC

$ORDER traverses numeric subscripts in numeric order: 1, 2, 3, 10\. So the output is arr(1)\="A", arr(2)\="D", arr(3)\="B", arr(10)\="C" \= "ADBC". The insertion order does not matter; canonical ordering always applies. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_forder))

</details>
