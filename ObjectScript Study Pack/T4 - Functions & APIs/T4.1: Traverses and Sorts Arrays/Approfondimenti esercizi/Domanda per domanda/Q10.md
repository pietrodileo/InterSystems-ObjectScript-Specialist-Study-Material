# T4.1 · Q10 — Maiuscole e collazione

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-10-single>)

## Il passaggio che risolve l’esercizio

Nel contesto mostrato ABC precede Abc, che precede abc; i valori corrispondenti producono 231.

## Che cosa insegna in più

Non generalizzare un ordine ASCII a ogni collazione configurabile. Quando l’ordine è parte del contratto, controlla il contesto effettivo.

## Prova a cambiare il caso

Convertire tutte le chiavi a maiuscolo può mantenere tre voci distinte?

<details>
<summary>Ragionamento e risposta</summary>

Non se convergono sulla stessa chiave.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer sets up a configuration array and is confused by the sorting. Consider:

set cfg("abc") = 1
set cfg("ABC") = 2
set cfg("Abc") = 3
set key = ""
for {
  set key = $ORDER(cfg(key))
  quit:key=""
  write cfg(key)
}

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-10-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** 231

String subscripts are sorted in ASCII order. In ASCII, uppercase letters come before lowercase: 'A'\=65, 'a'\=97. So "ABC" (all uppercase) \< "Abc" (A then lowercase) \< "abc" (all lowercase). Output: cfg("ABC")\=2, cfg("Abc")\=3, cfg("abc")\=1 \= "231". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_variables#GCOS_variables_global_subscripts))

</details>
