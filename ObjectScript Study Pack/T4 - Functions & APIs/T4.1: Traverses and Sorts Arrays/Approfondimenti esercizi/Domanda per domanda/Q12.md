# T4.1 · Q12 — Discendenti senza valore intermedio

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-12-single>)

## Il passaggio che risolve l’esercizio

Il SET del nodo profondo crea un ramo con a,b come contenitore, senza assegnargli un valore: $DATA=10.

## Che cosa insegna in più

L’esistenza di un percorso fino a un figlio non implica un valore a ogni livello intermedio.

## Prova a cambiare il caso

Leggere direttamente ^data(a,b) è sicuro solo perché c esiste?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 3. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A reporting module stores data in a deep hierarchy. Consider:

set ^data("a","b","c") = "deep"
write $DATA(^data("a","b"))

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-12-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** 10

^data("a","b") was never explicitly assigned a value, but it has a descendant node at ("a","b","c"). Therefore $DATA returns 10: no value at this node, but descendants exist. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fdata))

</details>
