# T4.2 · Q10 — Ricerca dell’elemento esatto

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-10-single>)

## Il passaggio che risolve l’esercizio

LISTFIND trova Viewer alla posizione tre e restituisce zero se non lo trova.

## Che cosa insegna in più

Questo è utile per appartenenza a un insieme rappresentato da lista: evita falsi positivi dovuti a sottostringhe.

## Prova a cambiare il caso

SuperViewer equivale all’elemento Viewer nella ricerca esatta?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 3; Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are searching for a specific role in a user's role list. Consider:

set roles = $LISTBUILD("Admin", "Editor", "Viewer", "Auditor")
write $LISTFIND(roles, "Viewer")

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-10-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 3

$LISTFIND searches for an element in a list and returns its 1-based position. "Viewer" is at position 3\. If the element is not found, $LISTFIND returns 0\. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_flistfind))

</details>
