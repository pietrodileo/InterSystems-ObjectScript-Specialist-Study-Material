# T4.2 · Q03 — Omissione e stringa vuota

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-3-single>)

## Il passaggio che risolve l’esercizio

L’elemento omesso usa il default N/A; un elemento esplicitamente vuoto resta vuoto.

## Che cosa insegna in più

Il default non è una sostituzione indiscriminata di ogni contenuto che sembra assente. Questa distinzione può rappresentare informazione utile.

## Prova a cambiare il caso

Con $LB(OrderA,"",Shipped), il secondo campo diventa N/A?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A data import routine encounters missing fields. Consider:

set row = $LISTBUILD("OrderA",,"Shipped")
write $LISTGET(row, 2, "N/A")

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-3-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** N/A

In $LISTBUILD("OrderA",,"Shipped"), position 2 is undefined (null) \- not an empty string, but truly undefined. $LISTGET with a default value returns "N/A" for an undefined element. If position 2 were an empty string ($LB("OrderA","","Shipped")), $LISTGET would return the empty string instead. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_flistget))

</details>
