# T4.2 · Q05 — Importare un formato delimitato

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

LISTFROMSTRING separa Tokyo,London,Paris nei tre elementi e la seconda posizione è London.

## Che cosa insegna in più

Questo è uno split sul delimitatore, non necessariamente un parser CSV completo con virgolette ed escape.

## Prova a cambiare il caso

Una città scritta come valore CSV tra virgolette contenente una virgola viene sempre gestita come un campo unico?

<details>
<summary>Ragionamento e risposta</summary>

Non dal solo split ingenuo.

</details>

## Testo dell’esercizio

```text
A CSV file parser needs to convert a line into a list. Consider:

set line = "Tokyo,London,Paris"
set cities = $LISTFROMSTRING(line, ",")
write $LISTGET(cities, 2)

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** London

$LISTFROMSTRING converts a delimited string into a $LISTBUILD list. Using "," as the delimiter, "Tokyo,London,Paris" becomes $LB("Tokyo","London","Paris"). Position 2 is "London". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_flistfromstring))

</details>
