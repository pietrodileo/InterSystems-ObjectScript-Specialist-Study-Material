# T4.7 · Q13 — Destinatari come collection

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-13-single>)

## Il passaggio che risolve l’esercizio

To.Insert aggiunge un destinatario alla collection; TextData è lo stream del corpo.

## Che cosa insegna in più

Una collection non è una semplice proprietà scalare: l’operazione deve mantenere la sua struttura. Controlla lo status dell’invio e gestisci configurazione e autenticazione previste.

## Prova a cambiare il caso

Assegnare una stringa arbitraria a To equivale sempre a Insert?

<details>
<summary>Ragionamento e risposta</summary>

Non è il contratto mostrato.

</details>

## Testo dell’esercizio

```text
set msg = ##class(%Net.MailMessage).%New()
set msg.From = "sender@test.com"
do msg.To.Insert("recipient@test.com")
set msg.Subject = "Test"
set msg.TextData.Write("Hello")
set smtp = ##class(%Net.SMTP).%New()
set smtp.smtpserver = "mail.test.com"
set sc = smtp.Send(msg)
```

<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** ```text
set msg = ##class(%Net.MailMessage).%New()
set msg.From = "sender@test.com"
do msg.To.Insert("recipient@test.com")
set msg.Subject = "Test"
set msg.TextData.Write("Hello")
set smtp = ##class(%Net.SMTP).%New()
set smtp.smtpserver = "mail.test.com"
set sc = smtp.Send(msg)
```

The correct pattern: (1) Create a %Net.MailMessage and configure From, To (via To.Insert), Subject, and body content (TextData stream or IsHTML). (2) Create a %Net.SMTP, set smtpserver. (3) Call smtp.Send(msg). The To property is a list that requires Insert() to add recipients. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GNET_email))
