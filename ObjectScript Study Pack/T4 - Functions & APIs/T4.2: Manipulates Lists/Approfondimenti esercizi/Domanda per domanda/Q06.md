# T4.2 · Q06 — Iteratore di lista e valori omessi

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-6-single>)

## Il passaggio che risolve l’esercizio

Il puntatore parte da zero e viene aggiornato da LISTNEXT mentre il risultato della funzione indica se c’è un altro elemento.

## Che cosa insegna in più

Se un elemento è omesso, il valore di output può diventare indefinito. Proteggi la lettura e usa un contatore separato se ti serve la posizione.

## Prova a cambiare il caso

Puoi incrementare ptr manualmente per saltare esattamente un elemento?

<details>
<summary>Ragionamento e risposta</summary>

Non è un indice pubblico di elemento.

</details>

## Testo dell’esercizio

```text
set ptr = 0
while $LISTNEXT(errors, ptr, msg) {
  write msg, !
}
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** ```text
set ptr = 0
while $LISTNEXT(errors, ptr, msg) {
  write msg, !
}
```

$LISTNEXT requires the pointer to be initialized to 0 before the first call. Each call advances the pointer internally and sets the value in msg. It returns 1 while elements remain and 0 when exhausted. $LISTNEXT is the most efficient way to iterate because it avoids recalculating offsets. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_flistnext))

</details>
