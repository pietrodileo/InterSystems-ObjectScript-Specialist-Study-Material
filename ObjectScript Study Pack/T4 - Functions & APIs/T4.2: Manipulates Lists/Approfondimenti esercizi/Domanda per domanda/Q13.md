# T4.2 · Q13 — Validità strutturale e validità del record

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-13-single>)

## Il passaggio che risolve l’esercizio

LISTVALID verifica se l’input è una lista codificata, non se contiene i campi richiesti dal dominio.

## Che cosa insegna in più

Dopo la verifica strutturale controlla numero di elementi, posizioni obbligatorie e valori ammessi.

## Prova a cambiare il caso

Una lista valida con un solo campo è automaticamente un paziente completo?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
You need to verify whether an incoming value is a valid list before processing. Consider:

set input = "not a list"
write $LISTVALID(input)

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-13-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 0

$LISTVALID returns 1 if the value is a valid $LISTBUILD list and 0 otherwise. A plain string "not a list" is not a valid list structure, so $LISTVALID returns 0\. This is the safe way to test before calling list functions. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_flistvalid))

</details>
