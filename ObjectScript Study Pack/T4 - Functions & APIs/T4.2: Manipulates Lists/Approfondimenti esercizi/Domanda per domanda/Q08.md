# T4.2 · Q08 — Sostituire un elemento

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-8-single>)

## Il passaggio che risolve l’esercizio

SET $LIST alla posizione due sostituisce Bannana con Banana senza cambiare gli altri elementi.

## Che cosa insegna in più

L’aggiornamento preserva il ruolo posizionale del campo. Non cerca tutte le occorrenze della parola nel testo.

## Prova a cambiare il caso

Se Bannana compare anche al quarto posto, viene corretta automaticamente anche lì?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A data correction routine needs to update a list element in place. Consider:

set items = $LISTBUILD("Apple", "Bannana", "Cherry")
set $LIST(items, 2) = "Banana"
write $LISTGET(items, 2)

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-8-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Banana

SET $LIST(list, position) \= value modifies the list in place, replacing the element at the specified position. After the correction, position 2 now contains "Banana" instead of the misspelled "Bannana". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_flist))

</details>
