# T4.2 · Q07 — Unire strutture compatibili

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-7-single>)

## Il passaggio che risolve l’esercizio

La concatenazione delle due rappresentazioni di lista produce quattro elementi nello stesso ordine.

## Che cosa insegna in più

La validità deriva dal formato delle due parti: concatenare un testo arbitrario ai byte di una lista non è la stessa operazione.

## Prova a cambiare il caso

Aggiungere la stringa edit direttamente ai byte della lista equivale a LISTBUILD(edit)?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 3; Further insights, panel 3. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are merging two lists of permissions. Consider:

set read = $LISTBUILD("view", "export")
set write = $LISTBUILD("edit", "delete")
set all = read _ write
write $LISTLENGTH(all)

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-7-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 4

Concatenating two $LISTBUILD lists with the \_ operator produces a valid combined list. $LB("view","export") \_ $LB("edit","delete") creates $LB("view","export","edit","delete"), which has 4 elements. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_lists))

</details>
