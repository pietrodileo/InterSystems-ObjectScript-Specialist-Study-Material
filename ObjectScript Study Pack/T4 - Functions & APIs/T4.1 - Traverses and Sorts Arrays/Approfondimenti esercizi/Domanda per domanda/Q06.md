# T4.1 · Q06 — Scansione inversa

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-6-single>)

## Il passaggio che risolve l’esercizio

Con direzione -1 e punto iniziale previsto, $ORDER trova la chiave finale 40.

## Che cosa insegna in più

La direzione riguarda l’ordinamento delle chiavi, non il confronto del valore di prezzo.

## Prova a cambiare il caso

La voce dal prezzo maggiore è sempre quella restituita come ultima?

<details>
<summary>Ragionamento e risposta</summary>

Solo se il modello delle chiavi lo garantisce, non per effetto di $ORDER.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You need to find the last item in a price list stored in a global. Consider:

set ^prices(10) = 9.99
set ^prices(20) = 14.99
set ^prices(30) = 24.99
set ^prices(40) = 39.99

Which code correctly retrieves the last subscript (40)?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** set last \= $ORDER(^prices(""), -1)

$ORDER with direction -1 starting from "" returns the last subscript in the array. $ORDER(^prices(""), -1) returns 40\. Starting from "" with direction 1 gives the first subscript; starting from "" with direction -1 gives the last. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_forder))

</details>
