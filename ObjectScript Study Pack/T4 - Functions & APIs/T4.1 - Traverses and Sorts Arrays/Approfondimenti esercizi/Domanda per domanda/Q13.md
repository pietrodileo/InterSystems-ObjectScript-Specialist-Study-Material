# T4.1 · Q13 — Forma canonica di una chiave numerica

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-13-single>)

## Il passaggio che risolve l’esercizio

1.10 è la stessa chiave numerica di 1.1 nel caso mostrato; la visita dei valori produce BDAC.

## Che cosa insegna in più

Una rappresentazione testuale non canonica può avere altre regole: distingui il numero usato nel codice da un codice stringa che deve conservare zeri.

## Prova a cambiare il caso

I numeri 1.10 e 1.1 possono rappresentare due misure ma due nodi distinti dello stesso array numerico?

<details>
<summary>Ragionamento e risposta</summary>

No, come chiave numerica coincidono.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You need to process decimal product IDs. Consider:

set arr(1.5) = "A"
set arr(1) = "B"
set arr(2) = "C"
set arr(1.10) = "D"
set key = ""
for {
  set key = $ORDER(arr(key))
  quit:key=""
  write arr(key)
}

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-13-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** BDAC

Numeric subscripts are sorted by numeric value. 1.10 is canonically equivalent to 1.1. The sort order is: 1, 1.1, 1.5, 2\. So: arr(1)\="B", arr(1.1)\="D", arr(1.5)\="A", arr(2)\="C" \= "BDAC". Trailing zeros are stripped in canonical form. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_variables#GCOS_variables_global_subscripts))

</details>
