# T4.1 · Q04 — Valore del contenitore e figli

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-4-single>)

## Il passaggio che risolve l’esercizio

warehouse ha Main e due discendenti: il risultato è 11.

## Che cosa insegna in più

Un nodo può svolgere contemporaneamente il ruolo di valore e di radice di un sottoalbero. Non serve scegliere una sola delle due possibilità.

## Prova a cambiare il caso

Eliminando solo il valore diretto ma conservando i figli, cosa ottieni?

<details>
<summary>Ragionamento e risposta</summary>

$DATA=10.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 3. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are debugging a routine that checks whether a global node has children. Consider:

set ^inventory("warehouse") = "Main"
set ^inventory("warehouse", "aisle1") = 50
set ^inventory("warehouse", "aisle2") = 30

write $DATA(^inventory("warehouse"))

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-4-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: D.** 11

$DATA returns 11 when a node has both a value AND descendant nodes. ^inventory("warehouse") has the value "Main" and also has child subscripts ("aisle1" and "aisle2"), so $DATA returns 11\. Return values: 0\=undefined, 1\=value only, 10\=descendants only, 11\=both. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fdata))

</details>
