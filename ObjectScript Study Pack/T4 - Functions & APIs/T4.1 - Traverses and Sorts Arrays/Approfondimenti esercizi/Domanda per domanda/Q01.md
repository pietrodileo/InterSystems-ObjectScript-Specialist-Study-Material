# T4.1 · Q01 — Chiavi numeriche prima delle stringhe

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-1-single>)

## Il passaggio che risolve l’esercizio

20 precede 100; le chiavi testuali vengono dopo nel contesto di collazione mostrato.

## Che cosa insegna in più

$ORDER ordina i subscritti, non i valori. La prima voce inserita e la prima voce visitata possono quindi differire.

## Prova a cambiare il caso

Se data(20) contiene Zebra e data(100) contiene Alpha, cambia la prima chiave?

<details>
<summary>Ragionamento e risposta</summary>

No: resta 20.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following array:

set data("apple") = 1
set data("banana") = 2
set data(100) = 3
set data(20) = 4

What is the first subscript returned by $ORDER(data(""))?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-1-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** 20

In canonical ordering, numeric subscripts come before string subscripts, and they are sorted numerically: 20 \< 100\. So $ORDER(data("")) returns 20 as the first subscript. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_variables#GCOS_variables_global_subscripts))

</details>
