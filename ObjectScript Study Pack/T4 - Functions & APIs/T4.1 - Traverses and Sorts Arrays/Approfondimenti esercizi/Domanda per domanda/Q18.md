# T4.1 · Q18 — Contare gli avanzamenti sul giusto insieme

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-18-single>)

## Il passaggio che risolve l’esercizio

Le prime tre chiavi sono 100,200,500; Internal è il valore della terza, prima delle chiavi testuali.

## Che cosa insegna in più

Un codice numerico e un codice alfanumerico possono coesistere ma non vengono ordinati come una sola sequenza di testo.

## Prova a cambiare il caso

Il terzo avanzamento corrisponde alla terza riga scritta nel programma?

<details>
<summary>Ragionamento e risposta</summary>

Non necessariamente: conta l’ordine dei subscritti.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are building an index of error codes. Consider:

set ^errors(100) = "Timeout"
set ^errors(200) = "Not Found"
set ^errors("AUTH01") = "Unauthorized"
set ^errors("AUTH02") = "Forbidden"
set ^errors(500) = "Internal"

set key = ""
set key = $ORDER(^errors(key))
set key = $ORDER(^errors(key))
set key = $ORDER(^errors(key))
write ^errors(key)
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-18-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Internal

Canonical ordering: numeric subscripts come first sorted numerically (100, 200, 500), then string subscripts sorted by ASCII ("AUTH01", "AUTH02"). The first $ORDER from "" returns 100, the second from 100 returns 200, the third from 200 returns 500\. ^errors(500) \= "Internal". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_forder))

</details>
