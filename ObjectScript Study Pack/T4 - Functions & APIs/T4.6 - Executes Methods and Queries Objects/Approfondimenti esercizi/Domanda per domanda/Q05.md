# T4.6 · Q05 — Factory con classe scelta a runtime

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

CLASSMETHOD chiama %New sulla classe User.Person scelta nella variabile.

## Che cosa insegna in più

Una factory utile controlla che la classe scelta appartenga alla famiglia prevista e gestisce un risultato di costruzione fallito prima di usarlo.

## Prova a cambiare il caso

Se la costruzione restituisce vuoto, è sicuro chiamare subito %ClassName?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
You are writing a factory method that creates objects dynamically. Consider:

set className = "User.Person"
set obj = $CLASSMETHOD(className, "%New")
write obj.%ClassName(1)

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** User.Person

$CLASSMETHOD(className, "%New") dynamically calls %New on the User.Person class, creating a new instance. obj.%ClassName(1) then returns the full package-qualified class name "User.Person". This pattern is essential for factory methods and plugin architectures. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fclassmethod))

</details>
