# T4.6 · Q03 — Dispatch dinamico di classe

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-3-single>)

## Il passaggio che risolve l’esercizio

CLASSMETHOD seleziona la classe e il metodo da stringhe, poi inoltra gli argomenti.

## Che cosa insegna in più

La possibilità tecnica di invocare un nome non autorizza qualunque nome esterno. Limita i target previsti dal contratto di configurazione.

## Prova a cambiare il caso

Un parametro HTTP dovrebbe scegliere liberamente ogni classe e metodo?

<details>
<summary>Ragionamento e risposta</summary>

No, valida la selezione rispetto ai target ammessi.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A plugin system needs to call class methods dynamically based on configuration. Consider:

set className = "App.Plugins.EmailNotifier"
set methodName = "Send"
set sc = $CLASSMETHOD(className, methodName, "Hello", "user@test.com")

Which statement best describes this code?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-3-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** It calls the class method Send on App.Plugins.EmailNotifier with two arguments

$CLASSMETHOD dynamically invokes a class method. First argument is the class name, second is the method name, followed by any arguments. This is equivalent to ##class(App.Plugins.EmailNotifier).Send("Hello", "user@test.com") but allows the class and method names to be variables. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fclassmethod))

</details>
