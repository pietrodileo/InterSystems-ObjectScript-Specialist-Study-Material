# T3.4 · Q06 — Default per nuovi oggetti, backfill per vecchie righe

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-6-single>)

## Il passaggio che risolve l’esercizio

InitialExpression inizializza oggetti nuovi; non riempie gli slot mancanti di tutti i record già esistenti.

## Che cosa insegna in più

La migrazione deve distinguere il default futuro dal recupero storico. Scegli anche se un dato vecchio realmente ignoto debba ricevere un valore fittizio.

## Prova a cambiare il caso

Aggiungere Phone con default aggiorna automaticamente un milione di righe già salvate?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
A developer adds a new property to a class that already has 50,000 rows and compiles:

Class Sample.Person Extends %Persistent
{
Property Name As %String;
Property Email As %String;
Property Phone As %String [ InitialExpression = "000-000-0000" ];
}

The Phone property is newly added. After compiling, what value does Phone contain for existing rows?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** NULL (empty string) because existing global data has no value for the new slot

InitialExpression is only applied when a NEW object is created with %New(). Existing rows in the global have no data in the storage slot for Phone, so it reads as empty string (NULL in SQL). The class compilation does NOT modify existing global data. To set default values for existing rows, run an UPDATE statement or ObjectScript loop. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_storage))

</details>
