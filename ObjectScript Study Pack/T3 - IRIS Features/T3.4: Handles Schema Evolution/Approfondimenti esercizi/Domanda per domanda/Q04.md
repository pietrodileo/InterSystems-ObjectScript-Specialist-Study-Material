# T3.4 · Q04 — Riutilizzare uno slot consapevolmente

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-4-single>)

## Il passaggio che risolve l’esercizio

Nell’esempio FullName deve leggere la posizione 2 anziché la nuova posizione 4 vuota.

## Che cosa insegna in più

La correzione della mappa richiede compatibilità semantica: due nomi diversi possono condividere la stessa rappresentazione soltanto se il dato significa ancora la stessa cosa.

## Prova a cambiare il caso

Se FullName cambia anche struttura o codifica, basta rinominare il mapping?

<details>
<summary>Ragionamento e risposta</summary>

Non necessariamente: può servire migrare il valore.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer renamed a property from Name to FullName in a persistent class with 100,000 rows. After compiling, FullName returns empty for all existing rows. The developer examines the storage definition and sees:

<Data name="PersonDefaultData">
  <Value name="1"><Value>%%CLASSNAME</Value></Value>
  <Value name="2"><Value>Name</Value></Value>
  <Value name="3"><Value>DOB</Value></Value>
  <Value name="4"><Value>FullName</Value></Value>
</Data>

What should the developer do to make existing data accessible through the FullName property?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-4-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Change \<Value name\="2"\>\<Value\>Name\</Value\>\</Value\> to \<Value name\="2"\>\<Value\>FullName\</Value\>\</Value\> and remove slot 4

The fix is to edit the storage definition to map FullName to slot 2 (where the original Name data resides) and remove the unused slot 4\. This tells the runtime to read FullName from the same global position where Name data was stored. After the edit, recompile the class. No data migration is needed because the global data is unchanged. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_storage))

</details>

La risposta originale è conservata per confronto. Il commento didattico sopra distingue il risultato del quiz dalle generalizzazioni o dai difetti ulteriori del frammento. Le note del capitolo restano applicabili.
