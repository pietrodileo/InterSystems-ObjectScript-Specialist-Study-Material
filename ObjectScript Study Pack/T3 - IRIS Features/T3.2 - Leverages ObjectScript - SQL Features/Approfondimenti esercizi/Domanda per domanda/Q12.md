# T3.2 · Q12 — Macro e momento della sostituzione

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-12-single>)

## Il passaggio che risolve l’esercizio

$$$TaxRate viene sostituita con 0.07 prima dell’esecuzione; GetTax(100) calcola quindi 7.

## Che cosa insegna in più

Cambiare un file include non aggiorna magicamente il codice già compilato che ne aveva incorporato il valore.

## Prova a cambiare il caso

Se modifichi TaxRate a 0.08, cosa va considerato prima di attendersi 8?

<details>
<summary>Ragionamento e risposta</summary>

La ricompilazione del codice dipendente.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following macro definitions and usage:

Include MyApp.Constants

Class MyApp.Tax Extends %RegisteredObject
{

ClassMethod GetTax(amount As %Numeric) As %Numeric
{
    return amount * $$$TaxRate
}

}

The include file MyApp.Constants.inc contains:

#Define TaxRate 0.07
#Define MaxAmount 10000

What does GetTax(100) return?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-12-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 7

Macros are resolved at compile time by simple text substitution. $$$TaxRate is replaced with 0.07 before compilation, so the method body becomes: return amount \* 0.07. At runtime, 100 \* 0.07 \= 7\. Macros are compile-time constants and work seamlessly in any expression where their replacement text is valid. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_macros))

</details>
