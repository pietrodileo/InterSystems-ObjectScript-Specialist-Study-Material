# T3.2 · Q15 — Sommare oppure concatenare

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-15-single>)

## Il passaggio che risolve l’esercizio

5 apples + 3 oranges usa i prefissi e produce 8; underscore conserva i testi formando 5 apples3 oranges.

## Che cosa insegna in più

I separatori non vengono inseriti automaticamente dalla concatenazione. Se vuoi uno spazio, devi aggiungerlo esplicitamente.

## Prova a cambiare il caso

Per ottenere 5 apples 3 oranges quale dato aggiungi?

<details>
<summary>Ragionamento e risposta</summary>

Una stringa contenente lo spazio tra i due operandi.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following code:

set x = "5 apples"
set y = "3 oranges"
write x + y, " ", x _ y
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-15-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** 8 5 apples3 oranges

The \+ operator performs arithmetic: "5 apples" has numeric value 5 and "3 oranges" has numeric value 3, so 5 \+ 3 \= 8\. The \_ operator performs string concatenation: "5 apples" \_ "3 oranges" \= "5 apples3 oranges". This demonstrates the fundamental difference between \+ (arithmetic) and \_ (concatenation) in ObjectScript's weak typing system. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators))

</details>
