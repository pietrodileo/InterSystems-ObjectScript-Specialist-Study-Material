# T3.5 · Q06 — Cronometro con unità esplicite

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-6-single>)

## Il passaggio che risolve l’esercizio

La differenza fra letture di $ZH misura un intervallo numerico con frazioni di secondo.

## Che cosa insegna in più

Distingui durata, timestamp e numero di iterazioni. Etichettare le unità evita di confondere secondi medi e millisecondi complessivi.

## Prova a cambiare il caso

2.5 secondi per 100 iterazioni quanto fanno in media?

<details>
<summary>Ragionamento e risposta</summary>

0.025 secondi, cioè 25 ms.

</details>

## Testo dell’esercizio

```text
A developer wants to time how long a code block takes to execute:

set start = $ZH
for i = 1:1:100000 {
    set x = $PIECE("A,B,C,D,E", ",", 3)
}
set elapsed = $ZH - start
write "Elapsed: ", elapsed, " seconds"

Why is $ZH preferred over $HOROLOG for timing?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** $ZH provides fractional-second precision and simple arithmetic, while $HOROLOG uses comma-separated date,seconds format

$ZH ($ZHOROLOG) returns a high-resolution timestamp as a single number with fractional seconds, making subtraction straightforward. $HOROLOG returns 'days,seconds' format (e.g., '67339,45123') where the comma makes arithmetic complex and it only has whole-second granularity. For code timing, $ZH is the standard choice. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_vzhorolog))

</details>
