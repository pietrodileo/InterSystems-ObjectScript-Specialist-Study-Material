# T3.3 · Q07 — Popolazione della media

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-7-single>)

## Il passaggio che risolve l’esercizio

SUM ignora i NULL e vale 60; COUNT(Score)=3; AVG divide per tre, mentre COUNT(*) conta cinque righe.

## Che cosa insegna in più

Sostituire i NULL con zero cambia il significato della media: non è soltanto una correzione cosmetica dell’output.

## Prova a cambiare il caso

Con zero al posto dei due NULL, quale media ottieni?

<details>
<summary>Ragionamento e risposta</summary>

60/5=12 invece di 20.

</details>

## Testo dell’esercizio

```text
Consider the following table and query:

&sql(INSERT INTO Sample.Exam (Score) VALUES (10))
&sql(INSERT INTO Sample.Exam (Score) VALUES (NULL))
&sql(INSERT INTO Sample.Exam (Score) VALUES (20))
&sql(INSERT INTO Sample.Exam (Score) VALUES (NULL))
&sql(INSERT INTO Sample.Exam (Score) VALUES (30))

&sql(SELECT AVG(Score) INTO :avg,
            SUM(Score) INTO :total,
            COUNT(Score) INTO :cnt,
            COUNT(*) INTO :allRows
     FROM Sample.Exam)

write avg, " ", total, " ", cnt, " ", allRows
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-7-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 20 60 3 5

SQL aggregate functions (except COUNT(\*)) ignore NULL values. SUM(Score) \= 10\+20\+30 \= 60\. COUNT(Score) \= 3 (non-NULL values only). AVG(Score) \= 60/3 \= 20\. COUNT(\*) \= 5 (counts all rows regardless of NULL). This is standard SQL behavior \- NULL values are excluded from aggregation but COUNT(\*) counts rows, not values. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RSQL_avg))

</details>
