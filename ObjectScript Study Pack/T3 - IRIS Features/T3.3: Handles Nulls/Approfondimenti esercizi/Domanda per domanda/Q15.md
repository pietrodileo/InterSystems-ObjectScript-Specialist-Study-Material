# T3.3 · Q15 — Fallback e collisione con dati reali

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-15-single>)

## Il passaggio che risolve l’esercizio

Solo la riga con A e B entrambi NULL raggiunge il fallback none nell’esempio.

## Che cosa insegna in più

Se none può essere anche un valore reale, confrontare il risultato di COALESCE con none non prova che entrambi i campi fossero NULL.

## Prova a cambiare il caso

A='none' e B=NULL soddisfa lo stesso confronto?

<details>
<summary>Ragionamento e risposta</summary>

Sì: per cercare entrambi assenti usa i test IS NULL sui campi.

</details>

## Testo dell’esercizio

```text
Consider the following SQL statements:

&sql(CREATE TABLE Sample.NullTest (A VARCHAR(10), B VARCHAR(10)))
&sql(INSERT INTO Sample.NullTest VALUES ('X', NULL))
&sql(INSERT INTO Sample.NullTest VALUES (NULL, 'Y'))
&sql(INSERT INTO Sample.NullTest VALUES (NULL, NULL))

&sql(SELECT COUNT(*) INTO :cnt FROM Sample.NullTest
     WHERE COALESCE(A, B, 'none') = 'none')
write cnt
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-15-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 1

COALESCE returns the first non-NULL argument. Row 1: COALESCE('X', NULL, 'none') \= 'X'. Row 2: COALESCE(NULL, 'Y', 'none') \= 'Y'. Row 3: COALESCE(NULL, NULL, 'none') \= 'none'. Only row 3 produces 'none', so cnt \= 1\. COALESCE is essential for providing fallback values when columns may be NULL. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RSQL_coalesce))

</details>
