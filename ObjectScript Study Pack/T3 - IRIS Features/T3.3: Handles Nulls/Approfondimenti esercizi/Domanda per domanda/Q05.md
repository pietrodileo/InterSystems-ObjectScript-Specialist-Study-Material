# T3.3 · Q05 — Verità numerica e uguaglianza

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

I due valori diversi producono entrambi falso quando interpretati numericamente dall’IF.

## Che cosa insegna in più

Essere falso in una condizione non rende due valori identici. Lo stesso vale per altre stringhe con conversione numerica zero.

## Prova a cambiare il caso

Puoi usare IF val come test universale di stringa non vuota?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 3; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following ObjectScript code:

set val = ""
if val {
    write "truthy"
} else {
    write "falsy"
}
write " | "
set val2 = $CHAR(0)
if val2 {
    write "truthy"
} else {
    write "falsy"
}
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** falsy \| falsy

In ObjectScript, the if command evaluates expressions numerically. The empty string "" has numeric value 0, so it is falsy. $CHAR(0) also has numeric value 0 (it is a string that does not begin with a digit), so it is also falsy. Both produce "falsy". Even though they are different values ($LENGTH-wise), they share the same numeric coercion to 0\. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators))

</details>
