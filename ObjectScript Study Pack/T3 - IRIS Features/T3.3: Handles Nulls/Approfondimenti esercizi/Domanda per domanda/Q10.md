# T3.3 · Q10 — Confronto esplicito con stringa vuota

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-10-single>)

## Il passaggio che risolve l’esercizio

IsEmpty confronta con la stringa vuota e distingue $CHAR(0) e zero, entrambi non uguali al vuoto.

## Che cosa insegna in più

Test di uguaglianza e interpretazione numerica di IF hanno scopi diversi. Scegli in base al significato di assenza del tuo campo.

## Prova a cambiare il caso

Una quantità numerica zero è necessariamente un campo mancante?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
A developer writes the following ObjectScript code to check for null values:

ClassMethod IsEmpty(val As %String) As %Boolean
{
    if val = "" quit 1
    quit 0
}

write ##class(MyApp.Utils).IsEmpty(""), " "
write ##class(MyApp.Utils).IsEmpty($CHAR(0)), " "
write ##class(MyApp.Utils).IsEmpty(0)
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-10-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 1 0 0

"" \= "" is 1 (true). $CHAR(0) \= "" is 0 (false, $CHAR(0) is a different string from empty string). 0 \= "" is 0 (false) because the \= operator only performs numeric comparison when BOTH operands have numeric values. The empty string "" is not a numeric value, so this is a string comparison: the string "0" does not equal the empty string "". This is a key behavior of ObjectScript's \= operator. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators))

</details>
