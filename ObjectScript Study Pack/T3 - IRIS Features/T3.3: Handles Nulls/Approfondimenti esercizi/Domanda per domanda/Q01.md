# T3.3 · Q01 — Lunghezza zero contro carattere zero

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-1-single>)

## Il passaggio che risolve l’esercizio

La stringa vuota non contiene caratteri; $CHAR(0) ne contiene uno. Il confronto è falso.

## Che cosa insegna in più

Un carattere invisibile può essere presente e significativo. Per capirlo osserva lunghezza e codice, non soltanto l’output sullo schermo.

## Prova a cambiare il caso

Se entrambi sembrano vuoti al Terminal, sono necessariamente uguali?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
Consider the following ObjectScript code:

set a = ""
set b = $CHAR(0)
write a = b
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-1-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 0 (false) \- $CHAR(0) is a single character, "" is an empty string

$CHAR(0) produces a single character (the NUL character, ASCII code 0\) with $LENGTH of 1\. The empty string "" has $LENGTH of 0\. They are different values. In ObjectScript, $CHAR(0) is a valid character that can appear in strings, not a synonym for empty or NULL. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fchar))

</details>
