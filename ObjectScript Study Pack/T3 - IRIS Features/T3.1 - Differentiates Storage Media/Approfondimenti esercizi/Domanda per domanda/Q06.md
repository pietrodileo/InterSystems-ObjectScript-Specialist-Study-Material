# T3.1 · Q06 — Ricostruibilità dei dati intermedi

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-6-single>)

## Il passaggio che risolve l’esercizio

La PPG è adatta a parsed se i dati possono essere rigenerati e non devono sopravvivere al processo o al riavvio.

## Che cosa insegna in più

La scelta dello storage è anche una scelta sul recupero. Conserva separatamente ciò che permette di ripetere o riprendere l’import, se il requisito lo richiede.

## Prova a cambiare il caso

Puoi usare solo parsed come checkpoint duraturo dopo un arresto?

<details>
<summary>Ragionamento e risposta</summary>

## Testo dell’esercizio

```text
Consider the following method that processes a large file:

ClassMethod ProcessFile(path As %String) As %Status
{
    set stream = ##class(%Stream.FileCharacter).%New()
    do stream.LinkToFile(path)
    set lineNum = 0
    while 'stream.AtEnd {
        set line = stream.ReadLine()
        set lineNum = lineNum + 1
        set ^||parsed(lineNum) = $PIECE(line, ",", 1, 5)
    }
    // ... further processing of ^||parsed ...
    quit $$$OK
}

Which statements about ^||parsed are correct?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** ^\|\|parsed is stored in IRISTEMP and not journaled, so data is lost on a crash

Process-private globals are stored in the IRISTEMP database, which is not journaled. If the system crashes during processing, the ^\|\|parsed data is lost. This is acceptable for temporary processing data that can be regenerated. PPGs are not stored in process memory (that is local variables) nor in the default namespace database. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_variables#GCOS_variables_ppg))

</details>
