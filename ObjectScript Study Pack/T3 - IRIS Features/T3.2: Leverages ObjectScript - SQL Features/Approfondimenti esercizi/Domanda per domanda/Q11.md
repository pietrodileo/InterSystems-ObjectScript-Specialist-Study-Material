# T3.2 · Q11 — Coercizione non è ricerca delle cifre

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-11-single>)

## Il passaggio che risolve l’esercizio

3.14abc diventa 3.14 per l’aritmetica; abc3.14 e stringa vuota contribuiscono come zero.

## Che cosa insegna in più

La stessa funzione applicata a input malformati può restituire numeri plausibili. Una risposta numerica non prova che l’input fosse valido.

## Prova a cambiare il caso

Quale controllo manca se accetti il risultato 1 per abc3.14+1 come misura valida?

<details>
<summary>Ragionamento e risposta</summary>

La validazione dell’intera rappresentazione numerica.

</details>

## Testo dell’esercizio

```text
What is the result of the following ObjectScript expressions?

set a = "3.14abc" + 1
set b = "abc3.14" + 1
set c = "" + 1
write a, " ", b, " ", c
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-11-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 4.14 1 1

ObjectScript extracts the leading numeric portion of a string for arithmetic. "3.14abc" has numeric value 3.14, so a \= 4.14. "abc3.14" starts with a non-digit, so its numeric value is 0, making b \= 1\. The empty string "" has numeric value 0, so c \= 1\. No errors are thrown \- weak typing silently coerces all values. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators#GCOS_operators_arith))

</details>
