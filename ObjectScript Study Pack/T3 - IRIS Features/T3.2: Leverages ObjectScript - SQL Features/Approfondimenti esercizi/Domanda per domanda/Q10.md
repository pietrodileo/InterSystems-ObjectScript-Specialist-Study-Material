# T3.2 · Q10 — Tre risultati dell’INSERT

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-10-single>)

## Il passaggio che risolve l’esercizio

SQLCODE descrive l’esito, %ROWCOUNT il numero di righe e %ROWID l’identità generata nello scenario.

## Che cosa insegna in più

Il numero di righe non è l’ID. Leggi questi valori prima di eseguire altre istruzioni che possano aggiornarne il contesto.

## Prova a cambiare il caso

Se la nuova riga ha ID 700, %ROWCOUNT deve valere 700?

<details>
<summary>Ragionamento e risposta</summary>

No: vale uno per l’inserimento singolo riuscito.

</details>

Visual connection: Core mechanisms, panel 3; Further insights, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer executes the following code:

&sql(INSERT INTO Sample.Person (Name, City) VALUES ('Jane Doe', 'Boston'))
write "SQLCODE: ", SQLCODE, !
write "ROWCOUNT: ", %ROWCOUNT, !
write "ROWID: ", %ROWID, !

The insert succeeds. Which output is correct?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-10-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** SQLCODE: 0, ROWCOUNT: 1, ROWID: (the new row's ID)

After a successful INSERT: SQLCODE \= 0 (success), %ROWCOUNT \= 1 (one row inserted), and %ROWID contains the RowID of the newly inserted row. SQLCODE \= 100 means no data found (used for SELECT). SQLCODE \= 1 is not a standard value. %ROWID is particularly useful for retrieving the auto-assigned ID of a new row. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RSQL_variables))

</details>
