# T3.2 · Q01 — Operatore aritmetico su testo

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-1-single>)

## Il passaggio che risolve l’esercizio

A e B non forniscono un prefisso numerico utile: con + entrano nel calcolo come zero nello scenario.

## Che cosa insegna in più

Il linguaggio non deduce l’intenzione di concatenare dal tipo visivo degli operandi. L’operatore scelto determina l’operazione.

## Prova a cambiare il caso

Per ottenere AB quale operatore usi?

<details>
<summary>Ragionamento e risposta</summary>

La concatenazione con underscore.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Which of the following is the result of this expression?

"A" + "B"
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-1-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: E.** 0

ObjectScript is weakly typed and the \+ operator is always arithmetic addition. When a string does not begin with a digit, its numeric value is 0\. Both "A" and "B" evaluate to 0, so "A" \+ "B" \= 0 \+ 0 \= 0\. String concatenation requires the \_ operator, not \+. No error is thrown because type coercion is automatic. (Reference: InterSystems Practice Question Q16; [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_operators#GCOS_operators_arith))

</details>
