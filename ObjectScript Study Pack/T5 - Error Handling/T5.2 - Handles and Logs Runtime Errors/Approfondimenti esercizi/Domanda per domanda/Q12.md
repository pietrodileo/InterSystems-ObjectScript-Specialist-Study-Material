# T5.2 · Q12 — Posizione nel codice compilato

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-12-single>)

## Il passaggio che risolve l’esercizio

Location usa label+offset^routine e aiuta a individuare il punto del guasto.

## Che cosa insegna in più

L’offset del compilato non è necessariamente il numero di riga del file sorgente corrente. Conserva il contesto di versione e mappatura quando indaghi.

## Prova a cambiare il caso

Aprire la riga sette del file modificato oggi identifica sempre ProcessOrder+7 del guasto di ieri?

<summary>Ragionamento e risposta</summary>

No.

## Testo dell’esercizio

```text
What information does the Location property of a %Exception.AbstractException contain?

For example, if ex.Location returns: "ProcessOrder+7^App.OrderService.1"
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-12-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** The label\+offset^routine reference where the error was thrown

The Location property contains the execution location in the format label\+offset^routine. In this example, 'ProcessOrder\+7^App.OrderService.1' means the error occurred 7 lines into the ProcessOrder label of the compiled routine App.OrderService.1. This helps pinpoint exactly where the error was thrown. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_ctrycatch))

</details>
