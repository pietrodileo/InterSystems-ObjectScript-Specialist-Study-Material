# T5.2 · Q02 — Tradurre un’eccezione in status

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-2-single>)

## Il passaggio che risolve l’esercizio

AsStatus rende l’errore adatto a un contratto che restituisce %Status invece di propagare un’eccezione.

## Che cosa insegna in più

La traduzione non risolve il guasto. Il chiamante deve ancora controllare e trattare il risultato negativo.

## Prova a cambiare il caso

Dopo AsStatus è corretto ignorare il valore e restituire OK?

<details>
<summary>Ragionamento e risposta</summary>

No, se l’operazione non è stata recuperata.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer writes the following error handler:

ClassMethod ProcessBatch() As %Status
{
  TRY {
    Do ..LoadData()
    Do ..TransformData()
    Do ..SaveResults()
    Return $$$OK
  } CATCH ex {
    Write "Error: ", ex.Name, " at ", ex.Location, !
    Return ex.AsStatus()
  }
}

What does ex.AsStatus() return in the CATCH block?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-2-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** A %Status error value representing the caught exception

The AsStatus() method of %Exception.AbstractException converts the exception object back into a %Status error value. This allows seamless integration between exception-based error handling (TRY-CATCH) and %Status-based error handling (returning status codes to callers). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_ctrycatch))

</details>
