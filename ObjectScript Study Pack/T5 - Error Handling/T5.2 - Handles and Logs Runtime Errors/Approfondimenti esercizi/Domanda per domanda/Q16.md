# T5.2 · Q16 — RETURN di errore non attiva CATCH

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-16-single>)

## Il passaggio che risolve l’esercizio

Il codice riconosce lo status di Step1 e lo restituisce direttamente; non viene lanciata un’eccezione.

## Che cosa insegna in più

TRY non trasforma ogni valore negativo in un evento di controllo. Questo spiega perché un CATCH può non essere raggiunto anche se l’operazione fallisce.

## Prova a cambiare il caso

Per arrivare intenzionalmente al CATCH con quel risultato, cosa manca?

<details>
<summary>Ragionamento e risposta</summary>

Una conversione e un throw appropriati.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer writes:

ClassMethod RunJob() As %Status
{
    TRY {
        Set sc = ..Step1()
        If $$$ISERR(sc) Return sc
        Set sc = ..Step2()
        If $$$ISERR(sc) Return sc
        Return $$$OK
    } CATCH ex {
        Return ex.AsStatus()
    }
}

What happens if Step1() returns an error %Status?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-16-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** The method returns the error %Status from Step1() \-- the CATCH block is not entered

The 'If $$$ISERR(sc) Return sc' pattern returns the error status directly from the method via Return. Since no exception is thrown, the CATCH block is never entered. The CATCH block only activates when an actual exception (throw or runtime error) occurs, not when a %Status error is returned via Return. Note: RETURN (not QUIT) must be used inside TRY/CATCH blocks, as QUIT with an argument inside TRY produces compile error #1043. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_ctrycatch))

</details>
