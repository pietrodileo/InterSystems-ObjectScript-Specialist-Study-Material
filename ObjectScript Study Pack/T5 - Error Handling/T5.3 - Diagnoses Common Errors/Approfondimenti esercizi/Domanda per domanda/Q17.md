# T5.3 · Q17 — Ciclo di grafo e ciclo di chiamate

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-17-single>)

## Il passaggio che risolve l’esercizio

Seguire Next dentro WHILE non aumenta necessariamente lo stack: un collegamento circolare può far ripetere gli stessi nodi indefinitamente.

## Che cosa insegna in più

Per rilevare un ciclo conserva i nodi già visitati; un semplice limite di iterazioni protegge la durata ma non spiega da solo la struttura difettosa.

## Prova a cambiare il caso

Il caso 1→2→3→1 richiede ricorsione per essere infinito?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
A developer writes a method that traverses a linked list stored in globals:

ClassMethod TraverseList(startId As %Integer)
{
    Set current = startId
    While current '= "" {
        Write ^LinkedList(current, "Value"), !
        Set current = ^LinkedList(current, "Next")
    }
}

The data has a circular reference: node 3's "Next" points back to node 1. What error occurs?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-17-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** No error terminates the code, but it runs in an infinite loop because the While condition is never false

This is not recursive (no method calls itself), so \<FRAMESTACK\> does not apply. The While loop follows the "Next" pointers endlessly since the circular reference means current never becomes "". The code runs in an infinite loop. The fix is to track visited nodes or set a maximum iteration count. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_errors))

</details>
