# T5.3 · Q13 — NEW non inizializza il valore

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-13-single>)

## Il passaggio che risolve l’esercizio

total viene letto nell’addizione prima di essere assegnato; SET total=0 definisce l’accumulatore.

## Che cosa insegna in più

Creare un nuovo ambito e assegnare un valore iniziale sono operazioni diverse. L’invariante della somma parte da zero, non da una variabile appena nascosta.

## Prova a cambiare il caso

NEW total da solo rende total+1 uguale a uno?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
A developer writes:

ClassMethod ProcessFile(filename As %String) As %Status
{
    Set stream = ##class(%Stream.FileCharacter).%New()
    Set sc = stream.LinkToFile(filename)
    While 'stream.AtEnd {
        Set line = stream.ReadLine()
        Set parts = $Length(line, ",")
        Set orderId = $Piece(line, ",", 1)
        Set total = total + $Piece(line, ",", 3)
    }
    Write "Grand total: ", total, !
    Quit $$$OK
}

On the first iteration, the method fails with <UNDEFINED> *total. What is the fix?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-13-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Add 'Set total \= 0' before the While loop

The variable 'total' is used in the expression 'total \+ $Piece(line, ",", 3)' before it has been assigned any value. On the first iteration, 'total' is undefined, causing \<UNDEFINED\>. The fix is to initialize it: 'Set total \= 0' before the While loop. The 'New' command creates a new scope for a variable but does not assign it a value. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_errors))

</details>
