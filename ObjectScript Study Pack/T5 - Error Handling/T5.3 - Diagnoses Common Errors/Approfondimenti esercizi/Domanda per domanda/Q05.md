# T5.3 · Q05 — Refuso e sensitività al caso

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

agee non è age e non è stato assegnato. L’errore emerge nel punto della lettura.

## Che cosa insegna in più

Non generalizzare dalle keyword senza distinzione di maiuscole ai nomi delle variabili, che devono corrispondere esattamente.

## Prova a cambiare il caso

AGE e age sono la stessa variabile perché WRITE e write sono lo stesso comando?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
What error does this code produce?

Set name = "John"
Set age = 30
Write "Name: " _ name _ ", Age: " _ agee
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** \<UNDEFINED\> \*agee because 'agee' is a typo for 'age'

The variable 'agee' (with double 'e') was never defined. ObjectScript variable names are case-sensitive and must match exactly, so 'agee' is a different variable from 'age'. This is one of the most common causes of \<UNDEFINED\> errors: simple typos in variable names. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_errors))

</details>
