# T5.3 · Q03 — Fine del ciclo prima della lettura

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-3-single>)

## Il passaggio che risolve l’esercizio

Spostando il controllo dopo WRITE si tenta di usare la chiave vuota prodotta alla fine della scansione.

## Che cosa insegna in più

Il problema è l’ordine di controllo e uso. Il tipo esatto di errore con subscritti nulli dipende anche da struttura e configurazione, non è universale.

## Prova a cambiare il caso

Abilitare subscritti nulli rende corretto visitare il sentinel come un record?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer runs the following code and gets a <SUBSCRIPT> error:

Set data(1) = "Alpha"
Set data(2) = "Beta"
Set data(3) = "Gamma"
Set key = ""
For {
    Set key = $Order(data(key))
    Quit:key=""
    Write data(key), !
}

Another developer modifies it to:

Set key = ""
For {
    Set key = $Order(data(key))
    Write data(key), !
    Quit:key=""
}

The modified version produces a <SUBSCRIPT> error. Why?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-3-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** The Quit:key\="" check moved AFTER Write data(key), so when $Order returns "" at the end, data("") is accessed before the loop exits

In the modified code, when $Order returns "" after the last node, the Write data("") executes BEFORE the Quit:key\="" check. Accessing data("") with an empty string subscript produces a \<SUBSCRIPT\> error. The original code correctly places Quit:key\="" before the Write, so the loop exits before attempting to read data(""). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_errors))

</details>
