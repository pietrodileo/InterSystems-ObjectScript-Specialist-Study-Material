# T5.3 · Q12 — Destinazione esplicita e privilegio effettivo

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-12-single>)

## Il passaggio che risolve l’esercizio

Il riferimento esteso sceglie una destinazione diversa: l’utente applicativo può non avere il permesso di scriverci.

## Che cosa insegna in più

Il fatto che il codice possa costruire un riferimento non ne autorizza l’esecuzione. Verifica anche che la destinazione sia davvero quella prevista dal dato applicativo.

## Testo dell’esercizio

```text
A developer tries to write to a global in the IRISSYS database:

Set ^["IRISSYS"]MyGlobal("key") = "value"

This produces a <PROTECT> error. What is the most likely reason?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-12-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** IRISSYS is a system database and the application user lacks Write permission on it

The IRISSYS database contains system data and is protected. Application users typically do not have Write permission to IRISSYS \-- only users with %All or specific system administration roles can write to it. This is a database-level \<PROTECT\> error. The extended global reference syntax is correct. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_errors))

</details>
