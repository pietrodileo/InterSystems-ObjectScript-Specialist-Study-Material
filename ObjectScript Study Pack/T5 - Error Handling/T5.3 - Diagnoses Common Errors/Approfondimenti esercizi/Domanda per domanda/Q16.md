# T5.3 · Q16 — Media senza argomenti

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-16-single>)

## Il passaggio che risolve l’esercizio

La lista variadica senza argomenti può lasciare il contatore indefinito; GET(scores,0) consente di rilevare n=0 prima di usarlo.

## Che cosa insegna in più

La guardia deve precedere sia il ciclo sia la divisione. Inizializzare n a zero e poi dividere per n sposta soltanto l’errore.

## Prova a cambiare il caso

Per n=0 esiste un risultato aritmetico obbligato della media?

<details>
<summary>Ragionamento e risposta</summary>

No, definisci un risultato di assenza o un errore applicativo.

</details>

## Testo dell’esercizio

```text
A developer debugs this code:

ClassMethod ComputeAverage(scores...) As %Numeric
{
    Set sum = 0
    For i = 1:1:scores {
        Set sum = sum + scores(i)
    }
    return sum / scores
}

Calling ##class(App.Math).ComputeAverage() with no arguments produces an error. Which error and why?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-16-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** \<UNDEFINED\> \*scores because the variadic array is not defined with zero arguments

When a variadic method (scores...) is called with no arguments, the 'scores' variable is NOT set at all — it is undefined. The very first reference to 'scores' in the For loop (For i \= 1:1:scores) produces an \<UNDEFINED\> \*scores error. The variable is not automatically initialized to 0\. The fix is to check '$GET(scores, 0)' or '$DATA(scores)' before using it. When called with arguments, 'scores' is set to the argument count and scores(1), scores(2), etc. hold the values. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_methods))

</details>
