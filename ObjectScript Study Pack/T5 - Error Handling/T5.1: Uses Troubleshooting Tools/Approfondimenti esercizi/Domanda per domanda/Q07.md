# T5.1 · Q07 — Sorgente presente e dipendenza compilata

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-7-single>)

## Il passaggio che risolve l’esercizio

La presenza del file sorgente di Base.Record non garantisce che il compilatore abbia la dipendenza disponibile nel contesto richiesto.

## Che cosa insegna in più

Controlla namespace, errori della superclasse e ordine delle dipendenze. La fonte propone altrove opzioni diverse: non inventare un flag dependencies dal nome plausibile.

## Prova a cambiare il caso

## Testo dell’esercizio

```text
A developer compiles several classes and one fails with:

ERROR #5501: Superclass 'App.Base.Record' does not exist

The App.Base.Record source file is present. What should the developer do?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-7-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Compile App.Base.Record first, then recompile the dependent subclass

When a superclass has not yet been compiled, subclasses that depend on it fail with 'does not exist' errors. The solution is to compile in dependency order \-- superclasses first. Using the /orderby\=d qualifier or compiling with the 'dependencies' option automates this. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_classes_compile))

</details>
