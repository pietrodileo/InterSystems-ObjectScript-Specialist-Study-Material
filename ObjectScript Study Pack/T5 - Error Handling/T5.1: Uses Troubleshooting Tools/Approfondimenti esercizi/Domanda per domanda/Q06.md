# T5.1 · Q06 — Refuso nel nome del tipo

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-6-single>)

## Il passaggio che risolve l’esercizio

%Strig non identifica il tipo %String atteso dalla proprietà.

## Che cosa insegna in più

Un errore di definizione del modello può fermare la compilazione prima che esista un percorso runtime da provare. Parti dall’identificatore segnalato.

## Prova a cambiare il caso

Cambiare i dati dell’oggetto corregge il nome del tipo nella classe?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

## Testo dell’esercizio

```text
A developer compiles a class and receives:

ERROR #5373: Property 'PatientName' in 'App.Record' is not a valid type

The property is defined as:

Property PatientName As %Strig;

What is the problem?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-6-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** The data type %Strig is misspelled \-- it should be %String

The type name '%Strig' is a typo for '%String'. The compiler reports 'not a valid type' because it cannot find a class named %Strig. This is a common compilation error caused by misspelling data type names in property definitions. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_properties))

</details>
