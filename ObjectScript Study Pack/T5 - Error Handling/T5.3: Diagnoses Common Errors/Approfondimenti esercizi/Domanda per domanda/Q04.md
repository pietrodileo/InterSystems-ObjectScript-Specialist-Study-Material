# T5.3 · Q04 — Terminazione e dominio del fattoriale

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-4-single>)

## Il passaggio che risolve l’esercizio

Il caso base ferma la discesa prima che n continui indefinitamente nei negativi.

## Che cosa insegna in più

Per un’API reale valida anche il dominio: n<=1 come ritorno uno non deve far apparire ogni numero negativo come un fattoriale valido.

## Prova a cambiare il caso

Accettare Factorial(-5)=1 è necessariamente corretto?

<details>
<summary>Ragionamento e risposta</summary>

No, serve una precondizione coerente.

</details>

## Testo dell’esercizio

```text
Consider this recursive method:

ClassMethod Factorial(n As %Integer) As %Integer
{
    return n * ..Factorial(n - 1)
}

Calling ##class(App.Math).Factorial(5) produces a <FRAMESTACK> error. How should it be fixed?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-4-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Add a base case: If n \<\= 1 { return 1 }

The method recurses infinitely because there is no base case to stop the recursion. When n reaches 0, it continues with -1, -2, etc., never stopping. Adding 'If n \<\= 1 { return 1 }' at the beginning provides the stopping condition that prevents infinite recursion and the resulting \<FRAMESTACK\> error. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_errors))

</details>
