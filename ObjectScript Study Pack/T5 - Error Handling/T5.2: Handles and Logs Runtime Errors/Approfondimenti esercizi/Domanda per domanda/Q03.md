# T5.2 · Q03 — Errore del caricamento oppure dell’uso

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-3-single>)

## Il passaggio che risolve l’esercizio

Il mancato record produce un valore vuoto; l’accesso successivo a Process genera INVALID OREF.

## Che cosa insegna in più

Per diagnosticare la causa iniziale controlla il risultato subito dopo OpenId, invece di aspettare l’errore secondario sulla dereferenziazione.

## Prova a cambiare il caso

Aggiungere il terzo argomento .sc rende automaticamente valido obj?

<details>
<summary>Ragionamento e risposta</summary>

No: devi ancora verificarlo.

</details>

## Testo dell’esercizio

```text
A developer writes:

TRY {
  Set obj = ##class(App.Order).%OpenId(999)
  Do obj.Process()
} CATCH ex {
  Write ex.Name, !
}

If ID 999 does not exist in the database, what error will be caught?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-3-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** \<INVALID OREF\> because obj is an empty string, not an object reference

When %OpenId cannot find the requested ID, it returns an empty string (""). The next line attempts to call obj.Process() on an empty string rather than an object reference, producing an \<INVALID OREF\> error. The safe pattern is to check 'If obj \= ""' after %OpenId, or use the %Status output parameter: Set obj \= ##class(App.Order).%OpenId(999, , .sc). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_errors))

</details>
