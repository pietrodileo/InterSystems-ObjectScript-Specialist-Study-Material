# T5.2 · Q04 — Ponte da status a eccezione

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-4-single>)

## Il passaggio che risolve l’esercizio

ThrowOnError continua con OK e genera una StatusException quando sc contiene un errore.

## Che cosa insegna in più

Scegli un punto esplicito dove convertire lo stile di gestione. Non presumere che ogni %Status negativo attivi già il CATCH.

## Prova a cambiare il caso

Senza ThrowOnError o altro THROW, uno status di errore entra da solo nel CATCH?

<details>
<summary>Ragionamento e risposta</summary>

No.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider this code that uses $$$ThrowOnError:

ClassMethod ProcessData() As %Status
{
  TRY {
    Set sc = ..ValidateInput()
    $$$ThrowOnError(sc)
    Set sc = ..TransformData()
    $$$ThrowOnError(sc)
    Set sc = ..SaveResults()
    $$$ThrowOnError(sc)
    Return $$$OK
  } CATCH ex {
    Return ex.AsStatus()
  }
}

What does $$$ThrowOnError(sc) do?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-4-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** Throws a %Exception.StatusException if sc is an error status; otherwise continues

$$$ThrowOnError(sc) checks whether sc is an error %Status. If it is, it throws a %Exception.StatusException that will be caught by the surrounding TRY-CATCH block. If sc indicates success ($$$OK), execution continues to the next line. This macro bridges %Status-based and exception-based error handling patterns. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_ctrycatch))

</details>
