# T5.2 · Q05 — Quale profondità dello stack

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

Il valore -1 è collegato al contesto informativo disponibile e non va generalizzato come sinonimo immutabile della profondità corrente.

## Che cosa insegna in più

Durante una gestione di errore possono essere disponibili frame relativi al punto del guasto. Usa i descrittori documentati e considera quando acquisisci l’informazione.

## Prova a cambiare il caso

Per il livello corrente basta sostituire a intuito ogni uso di STACK con STACK(-1)?

## Testo dell’esercizio

```text
A method needs to display the full call stack when an error occurs:

CATCH ex {
  Write "Error: ", ex.Name, !
  For level = 0:1:$STACK(-1) {
    Write "  Level ", level, ": ", $STACK(level, "PLACE"), !
  }
}

What does $STACK(-1) return?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** The current depth (number of levels) of the call stack

$STACK(-1) returns the current depth of the call stack as an integer. By looping from 0 to $STACK(-1) and calling $STACK(level, "PLACE") for each level, you can print the complete chain of method calls that led to the current execution point. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fstack))

</details>
