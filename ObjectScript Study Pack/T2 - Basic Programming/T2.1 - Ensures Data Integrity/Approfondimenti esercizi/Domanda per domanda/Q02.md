# T2.1 · Q02 — Rollback del solo livello interno

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-2-single>)

## Il passaggio che risolve l’esercizio

TROLLBACK 1 elimina total e items scritti nel livello più interno; status e notes restano nel livello esterno poi confermato.

## Che cosa insegna in più

Annotare il livello accanto a ogni modifica permette di capire il risultato senza contare soltanto i comandi SET.

## Prova a cambiare il caso

Se notes fosse scritto prima del rollback nel livello 2, sopravviverebbe?

<details>
<summary>Ragionamento e risposta</summary>

No, sarebbe fra le modifiche annullate di quel livello.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 3. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following code:

TSTART
SET ^Order(101,"status") = "Processing"
TSTART
SET ^Order(101,"total") = 250.00
SET ^Order(101,"items") = 3
TROLLBACK 1
SET ^Order(101,"notes") = "Reviewed"
TCOMMIT

After execution completes, which globals are committed?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-2-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Only ^Order(101,"status") and ^Order(101,"notes") are committed

TROLLBACK 1 rolls back only the innermost transaction level (the second TSTART), undoing the "total" and "items" SETs. $TLEVEL drops from 2 to 1\. The subsequent SET of "notes" occurs at level 1, and TCOMMIT commits everything at level 1: "status" and "notes". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_ctrollback))

</details>
