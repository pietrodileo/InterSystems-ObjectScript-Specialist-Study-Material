# T2.3 · Q07 — Isolamento temporaneo non è un controllo completo

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-7-single>)

## Il passaggio che risolve l’esercizio

La PPG riduce la condivisione involontaria fra processi e viene eliminata alla loro fine.

## Che cosa insegna in più

Non equivale a cifratura o isolamento fra utenti che riusano lo stesso processo. Non promette protezione da ogni strumento amministrativo o perdita tramite log.

## Prova a cambiare il caso

Due richieste servite in sequenza dallo stesso processo hanno automaticamente due PPG indipendenti?

<details>
<summary>Ragionamento e risposta</summary>

No: serve gestire anche il ciclo di vita dei dati.

</details>

## Testo dell’esercizio

```text
A developer stores sensitive query results during processing:

ClassMethod ProcessReport(query As %String)
{
  SET stmt = ##class(%SQL.Statement).%New()
  SET sc = stmt.%Prepare(query)
  SET rs = stmt.%Execute()
  WHILE rs.%Next() {
    SET ^||results($I(^||results)) = rs.%GetData(1)_"|"_rs.%GetData(2)
  }
  ; process ^||results
  ; ... done, process ends
}

What security benefit does using ^||results provide over ^results?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-7-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** ^\|\|results is isolated to the current process and automatically cleaned up when the process ends, preventing data leakage between concurrent processes

Process-private globals (^\|\|) are visible only to the creating process. Using ^\|\|results ensures no other process can access the sensitive query results, and they are automatically deleted when the process ends. With ^results, concurrent processes could see each other's data, and the data would persist after the process ends unless explicitly killed. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_globals#GCOS_globals_ppg))

</details>
