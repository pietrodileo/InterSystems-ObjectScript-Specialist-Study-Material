# T2.1 · Q18 — Dynamic SQL e percorso dopo il rollback

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-18-single>)

## Il passaggio che risolve l’esercizio

Dynamic SQL partecipa al contesto transazionale ObjectScript: non richiede una transazione separata per annullare quelle modifiche.

## Che cosa insegna in più

Il frammento usa QUIT nel ciclo dopo TROLLBACK e poi raggiunge TCOMMIT e $$$OK: riconoscere la transazione comune non rende corretto quel percorso d’errore. Evita commit fuori contesto e falso successo.

## Prova a cambiare il caso

Dopo il rollback, quale informazione va conservata?

<details>
<summary>Ragionamento e risposta</summary>

Il fallimento che deve interrompere il percorso di commit e arrivare al chiamante.

</details>

## Testo dell’esercizio

```text
Consider the following method that uses Dynamic SQL within a transaction:

ClassMethod BatchUpdate(items As %List) As %Status
{
  SET stmt = ##class(%SQL.Statement).%New()
  SET sc = stmt.%Prepare("UPDATE Inventory SET Status = 'Active' WHERE ItemId = ?")
  TSTART
  SET ptr = 0
  WHILE $LISTNEXT(items, ptr, itemId) {
    SET rs = stmt.%Execute(itemId)
    IF rs.%SQLCODE < 0 {
      TROLLBACK
      QUIT
    }
  }
  TCOMMIT
  QUIT $$$OK
}

Which statement about this code is correct?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-18-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** Both Dynamic SQL and Embedded SQL share the same transaction context as ObjectScript, so TROLLBACK correctly undoes all SQL changes

In InterSystems IRIS, Dynamic SQL executed via %SQL.Statement participates in the same transaction context as ObjectScript. TSTART/TCOMMIT/TROLLBACK apply to all global modifications, whether made by ObjectScript SET commands, Embedded SQL, or Dynamic SQL. The %Prepare call does not need to be inside the transaction. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=TOS_Transaction))

</details>
