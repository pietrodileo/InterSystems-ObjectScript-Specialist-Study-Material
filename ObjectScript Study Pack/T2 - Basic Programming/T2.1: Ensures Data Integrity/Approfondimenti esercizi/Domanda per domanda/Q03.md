# T2.1 · Q03 — Commit annidato e durabilità

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-3-single>)

## Il passaggio che risolve l’esercizio

I livelli stampati sono 1, 2, 1, 0. Il primo TCOMMIT chiude il livello interno, non rende definitiva una parte autonoma del lavoro.

## Che cosa insegna in più

Un metodo riutilizzabile può trovarsi già dentro una transazione del chiamante. Il suo TCOMMIT non deve essere raccontato come un commit esterno indipendente.

## Prova a cambiare il caso

Se il chiamante esegue rollback dopo il commit interno, i dati del metodo possono essere annullati?

<details>
<summary>Ragionamento e risposta</summary>

Sì.

</details>

Visual connection: Core mechanisms, panel 1; Further insights, panel 3. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer is debugging a method and adds logging:

TSTART
SET ^Inventory(itemId) = newQty
WRITE "$TLEVEL = ", $TLEVEL, !
TSTART
SET ^Inventory(itemId,"lastUpdate") = $HOROLOG
WRITE "$TLEVEL = ", $TLEVEL, !
TCOMMIT
WRITE "$TLEVEL = ", $TLEVEL, !
TCOMMIT
WRITE "$TLEVEL = ", $TLEVEL, !

What sequence of $TLEVEL values is printed?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-3-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 1, 2, 1, 0

After the first TSTART, $TLEVEL \= 1\. After the second TSTART, $TLEVEL \= 2\. The first TCOMMIT decrements it to 1\. The second TCOMMIT decrements it to 0 and actually commits the data. The real commit only occurs when $TLEVEL returns to 0\. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_vtlevel))

</details>
