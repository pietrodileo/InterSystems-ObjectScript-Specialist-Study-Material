# T2.2 · Q08 — Osservare l’intero albero

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-8-single>)

## Il passaggio che risolve l’esercizio

WRITE data mostra il valore radice; ZWRITE rende visibili anche A e B con i loro discendenti.

## Che cosa insegna in più

La rappresentazione di debug aiuta a distinguere valori, nodi intermedi e struttura. Un valore radice valido non dimostra che i sottonodi attesi esistano.

## Prova a cambiare il caso

Se data="test" ma data("B",1) manca, WRITE data rivela il problema?

<details>
<summary>Ragionamento e risposta</summary>

No, occorre ispezionare anche l’albero.

</details>

## Testo dell’esercizio

```text
A developer needs to display the contents of a complex local variable for debugging:

SET data = "test"
SET data("A") = 1
SET data("B",1) = "hello"
SET data("B",2) = "world"

Which command shows ALL values including subscripted nodes?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-8-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** ZWRITE data

ZWRITE displays a variable and all of its subscripts with their values in a structured, human-readable format. WRITE data would only output "test" (the top-level value). ZWRITE shows: data\="test", data("A")\=1, data("B",1)\="hello", data("B",2)\="world". There is no DISPLAY command in ObjectScript. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_czwrite))

</details>
