# T2.2 · Q03 — Nodo contenitore senza valore

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-3-single>)

## Il passaggio che risolve l’esercizio

Phone ha figli 1 e 2 ma nessun valore diretto: $DATA restituisce 10.

## Che cosa insegna in più

Un controllo booleano generico di $DATA non distingue valore leggibile e sola presenza di figli. Se vuoi leggere il nodo, verifica la componente relativa al valore.

## Prova a cambiare il caso

Aggiungendo anche Phone="principale", quale $DATA ottieni?

<details>
<summary>Ragionamento e risposta</summary>

11.

</details>

## Testo dell’esercizio

```text
Given the following global structure:

^Patient(1) = "Smith"
^Patient(1,"DOB") = "1990-01-15"
^Patient(1,"Phone",1) = "555-0100"
^Patient(1,"Phone",2) = "555-0200"

What is the result of executing:

WRITE $DATA(^Patient(1,"Phone"))
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-3-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** 10 \- the node has descendants but no data at this level

$DATA returns information about whether a node exists, has data, and/or has descendants. A return value of 10 means the node has descendant nodes (subscripts below it) but no value at that exact level. ^Patient(1,"Phone") has no direct value, but it has children at subscripts 1 and 2\. Values: 0\=doesn't exist, 1\=has data only, 10\=has descendants only, 11\=has both. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_fdata))

</details>
