# T2.2 · Q09 — Lista codificata e vista leggibile

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-9-single>)

## Il passaggio che risolve l’esercizio

ZWRITE riconosce la lista e la presenta come $LB, anziché usarne i byte come testo da leggere.

## Che cosa insegna in più

Una vista di debug leggibile non cambia la rappresentazione del valore. Per elaborarlo usa funzioni di lista, non posizioni della stringa visualizzata.

## Prova a cambiare il caso

Le parentesi e le virgole mostrate da ZWRITE sono delimitatori da cercare con $PIECE nel valore originale?

## Testo dell’esercizio

```text
A developer writes the following code:

SET x = $LISTBUILD("Alpha","Beta","Gamma")
ZWRITE x

What output is displayed?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-9-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** x\=$LB("Alpha","Beta","Gamma")

ZWRITE displays $LIST values in $LB() notation, showing the internal list representation. This is one of ZWRITE's key debugging benefits: it reveals the actual data type and structure of variables, including $LIST-encoded data that would be unreadable with a simple WRITE command (WRITE would show garbled binary data for $LIST values). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_czwrite))

</details>
