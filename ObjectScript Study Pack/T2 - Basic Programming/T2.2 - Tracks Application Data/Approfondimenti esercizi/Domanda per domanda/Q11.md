# T2.2 · Q11 — Requisito dell’interfaccia di osservazione

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-11-multiple>)

## Il passaggio che risolve l’esercizio

La domanda richiede il Terminal: ZWRITE e una scansione $ORDER rispondono a quel requisito. Una pagina del Portal può essere utile ma non è il Terminal.

## Che cosa insegna in più

Il vincolo “from the IRIS Terminal” riguarda l’interfaccia; tra le opzioni del quiz, `ZWRITE` e `$ORDER` sono le risposte corrette. C’è anche un’altra possibilità poco citata: `%Library.Global` espone le class query `Find` e `Get`, utilizzabili con SQL `CALL` in un contesto SQL o preparabili da ObjectScript tramite `%SQL.Statement`. Permettono di cercare o leggere global senza una definizione di classe persistente. Questo non rende valida la sintassi generica `SELECT * FROM %Global.MyGlobal` proposta dal distrattore.

Per esempio, in ObjectScript si può preparare `Find` per cercare il subscritto `Email` sotto `^Persons`; per i dettagli e l’esempio `Get`, vedi [la teoria sui global](<../../01 - Locates and accesses application globals/study.md>).

La scelta dello strumento e quella della profondità restano distinte: `ZWRITE` mostra una vista leggibile, `$ORDER` visita un livello per volta e `$QUERY` può attraversare i nodi a diversi livelli restituendo i riferimenti completi. Il Portal è una vista grafica, non il Terminal.

Per la distinzione fra `$ORDER` e `$QUERY`, con un esempio di scansione, vedi [la teoria sui global](<../../01 - Locates and accesses application globals/study.md#choosing-a-traversal-strategy>).

## Prova a cambiare il caso

Devi visitare tutte le foglie di un global annidato senza conoscere in anticipo la profondità: la scansione `$ORDER(^MyGlobal(""))` basta?

<details>
<summary>Ragionamento e risposta</summary>

No: `$ORDER(^MyGlobal(""))` visita i subscritti di primo livello. Puoi annidare i cicli `$ORDER` per controllare ogni livello oppure usare `$QUERY` per ottenere i riferimenti completi ai nodi.

</details>

## Testo dell’esercizio

```text

A developer needs to inspect the contents of a global from the IRIS Terminal. Which of the following are valid approaches?

**A.** ZWRITE ^MyGlobal to display the entire global with all subscripts and values

**B.** DO $SYSTEM.OBJ.ShowGlobal("MyGlobal") to display a formatted view

**C.** Using the Globals page in the Management Portal to browse the global visually

**D.** Using $ORDER(^MyGlobal("")) in a loop to iterate through top-level subscripts

**E.** SELECT \* FROM %Global.MyGlobal to query the global via SQL

### Answer and explanation

**Correct answer: A.** ZWRITE ^MyGlobal to display the entire global with all subscripts and values

**Correct answer: D.** Using $ORDER(^MyGlobal("")) in a loop to iterate through top-level subscripts

The question asks specifically about inspecting a global from the IRIS Terminal, so only the Terminal-based approaches count: ZWRITE ^MyGlobal displays the whole global, and $ORDER can walk the subscripts programmatically. The Management Portal's Globals page is a valid way to browse a global, but it is not the Terminal, so it does not answer this question. There is no $SYSTEM.OBJ.ShowGlobal method, and a global is not queryable with SELECT \* FROM %Global.MyGlobal. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_czwrite))

```
