# T1.1 · Q02 — Cancellare per chiave applicativa

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-2-single>)

## Il passaggio che risolve l’esercizio

JTE810 è MessageId, non l’ID interno. MIIdxDelete risolve la chiave univoca e identifica l’oggetto da eliminare.

## Che cosa insegna in più

Una stringa che sembra un identificativo non rivela quale spazio di identità usa l’API. Controlla sempre il contratto del metodo.

## Prova a cambiare il caso

Se MessageId fosse 42 e anche l’ID fosse 42, i due concetti diventerebbero equivalenti?

<details>
<summary>Ragionamento e risposta</summary>

No, coinciderebbero soltanto in quel record.

</details>

Visual connection: Core mechanisms, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following class definition.

Class Sample.EmailMessage Extends %Persistent
{
Property MessageId As %String;
Property MessageDate As %Date;
Property Sender As %String;
Property EmailType As %String;
Index MIIdx On MessageId [ Unique ];
Index ETIdx On EmailType [ Type = bitmap ];
}

One of the stored MessageId values is "JTE810".

Which of the following code deletes the record associated with "JTE810"?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-2-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: D.** set sc \= ##class(Sample.EmailMessage).MIIdxDelete("JTE810")

Since "JTE810" is a value of the MessageId property (not the object ID), you cannot use %DeleteId() or %Delete() which expect the object's internal row ID. The unique index MIIdx on MessageId generates a class method named MIIdxDelete() that deletes the record by looking up the unique index value and then deleting the corresponding object. This is a key feature of unique indexes in InterSystems IRIS. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_persobj))

</details>
