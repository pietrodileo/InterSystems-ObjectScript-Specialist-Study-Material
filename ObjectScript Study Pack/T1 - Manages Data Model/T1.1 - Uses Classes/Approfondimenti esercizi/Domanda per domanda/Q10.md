# T1.1 · Q10 — Location specifica e fallback

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-10-single>)

## Il passaggio che risolve l’esercizio

SKUIdx ha una Location propria, ^A1B2.C3D4.3. Il valore generico IndexLocation non annulla quella mappa esplicita.

## Che cosa insegna in più

Per diagnosticare uno specifico indice parti dal suo nome, non dall’insieme degli indici della classe.

## Prova a cambiare il caso

Cambiando soltanto IndexLocation, hai provato che SKUIdx sia stato spostato?

<details>
<summary>Ragionamento e risposta</summary>

No, devi rileggere la sua location effettiva.

</details>

Visual connection: Core mechanisms, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following storage definition with USEEXTENTSET enabled.

Class Inventory.Product Extends %Persistent
{
Parameter USEEXTENTSET = 1;
Property SKU As %String;
Property Description As %String;
Property Price As %Numeric;
Index SKUIdx On SKU [ Unique ];
Index PriceIdx On Price [ Type = bitmap ];

Storage Default
{
<DataLocation>^A1B2.C3D4.1</DataLocation>
<IdLocation>^A1B2.C3D4.1</IdLocation>
<Index name="PriceIdx">
<Location>^A1B2.C3D4.2</Location>
</Index>
<Index name="SKUIdx">
<Location>^A1B2.C3D4.3</Location>
</Index>
<IndexLocation>^A1B2.C3D4.I</IndexLocation>
<StreamLocation>^A1B2.C3D4.S</StreamLocation>
}
}

Which global contains the unique index on SKU?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-10-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** ^A1B2.C3D4.3

With USEEXTENTSET \= 1, each index is assigned its own hashed global name. The storage definition explicitly maps the SKUIdx index to ^A1B2.C3D4.3. The \<IndexLocation\> global (^A1B2.C3D4.I) is the fallback location for indexes that do not have explicit \<Location\> entries, but since SKUIdx has its own mapping, ^A1B2.C3D4.3 is the correct answer. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_storage))

</details>
