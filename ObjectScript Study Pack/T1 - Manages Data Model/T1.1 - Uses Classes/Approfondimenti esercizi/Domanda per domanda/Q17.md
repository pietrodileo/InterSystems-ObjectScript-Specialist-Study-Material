# T1.1 · Q17 — Utility senza istanza

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-17-single>)

## Il passaggio che risolve l’esercizio

Un ClassMethod basta per formattare una data senza conservare stato per oggetto. Abstract comunica che l’istanza non fa parte dell’interfaccia prevista.

## Che cosa insegna in più

Una costante o un helper non richiede automaticamente una classe persistente: la scelta della superclasse determina anche API e struttura generata.

## Prova a cambiare il caso

Se FormatDate diventa dipendente dal fuso scelto da ogni utente, dove rappresenti quel contesto?

<details>
<summary>Ragionamento e risposta</summary>

In un argomento o in uno stato esplicito, non in una persistenza introdotta senza necessità.

</details>

Visual connection: Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer needs to implement a utility class that provides shared helper methods for date formatting. No state needs to be maintained between calls.

Which of the following class definitions is the most appropriate approach?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-17-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** ```text
Class Utils.DateHelper [ Abstract ]
{
ClassMethod FormatDate(d As %Date) As %String
{
  return $ZDate(d, 3)
}
}
```

For a stateless utility class that only contains ClassMethods and no properties that need persistence, the most appropriate approach is an Abstract class that does not extend any superclass. Abstract utility classes cannot be instantiated (which is correct since no state is needed) and avoid the overhead of %RegisteredObject or %Persistent. Extending %Persistent would create unnecessary storage definitions and globals. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_classes))

</details>
