# T1.3 · Q11 — Trasformazione in posto

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-11-single>)

## Il passaggio che risolve l’esercizio

Transform riscrive i valori dell’array passato con il punto; le modifiche sono visibili direttamente nel chiamante.

## Che cosa insegna in più

Un’operazione in posto risparmia una copia ma cambia l’input. Documenta questa scelta, soprattutto se un altro passaggio richiede i valori originali.

## Prova a cambiare il caso

Dopo Transform puoi ricostruire sempre la capitalizzazione originale?

<details>
<summary>Ragionamento e risposta</summary>

No: la conversione in maiuscolo perde quell’informazione.

</details>

## Testo dell’esercizio

```text
Consider the following class.

Class App.Processor Extends %RegisteredObject
{
ClassMethod Transform(ByRef data As %String)
{
  set key = ""
  for {
    set key = $Order(data(key))
    quit:key=""
    set data(key) = $ZCONVERT(data(key), "U")
  }
}
}

// Caller:
set items("a") = "hello"
set items("b") = "world"
do ##class(App.Processor).Transform(.items)
write items("a"), " ", items("b")

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-11-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** HELLO WORLD

The array is passed by reference using the dot prefix (.items), which gives the Transform method access to all subscripts. The method iterates through each subscript using $Order and converts the values to uppercase using $ZCONVERT with the "U" flag. Since the array is passed by reference, the modifications to data(key) directly affect the caller's items array. The output is "HELLO WORLD". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_methods))

</details>
