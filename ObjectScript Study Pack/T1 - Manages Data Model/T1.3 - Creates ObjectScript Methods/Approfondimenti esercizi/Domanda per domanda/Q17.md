# T1.3 · Q17 — Concatenare liste non è concatenare campi delimitati

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-17-single>)

## Il passaggio che risolve l’esercizio

Ogni $LISTBUILD produce una rappresentazione di lista valida; concatenarle forma la sequenza di tre elementi nello scenario.

## Che cosa insegna in più

La struttura binaria mantiene i confini degli elementi anche quando il testo contiene un delimitatore. Non applicare $PIECE alla rappresentazione della lista.

## Prova a cambiare il caso

Un elemento Red,Green aggiunge due elementi?

<details>
<summary>Ragionamento e risposta</summary>

No: $LISTBUILD lo conserva come un unico valore stringa.

</details>

Visual connection: Core mechanisms, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following code.

Class App.Converter Extends %RegisteredObject
{
ClassMethod ToList(ByRef arr As %String, Output list As %List) As %Status
{
  set list = ""
  set key = ""
  for {
    set key = $Order(arr(key))
    quit:key=""
    set list = list _ $ListBuild(arr(key))
  }
  return $$$OK
}
}

// Caller:
set data(1) = "Red"
set data(2) = "Green"
set data(3) = "Blue"
set sc = ##class(App.Converter).ToList(.data, .result)
write $ListLength(result)

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-17-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 3

The method iterates through the arr subscripts (1, 2, 3\) using $Order and builds a $List by concatenating $ListBuild values. $List concatenation with \_ is valid and produces a longer $List. After processing all three elements, list contains $LB("Red", "Green", "Blue"), and $ListLength returns 3\. The data array is passed ByRef and result is passed as Output; both keywords pass by reference and neither affects runtime behavior (they are semantic hints for documentation). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=RCOS_flistbuild))

</details>
