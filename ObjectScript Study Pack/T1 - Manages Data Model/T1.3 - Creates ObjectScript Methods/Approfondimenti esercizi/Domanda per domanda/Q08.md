# T1.3 · Q08 — Valore utile e status separati

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-8-single>)

## Il passaggio che risolve l’esercizio

Divide scrive answer per riferimento e restituisce $$$OK. Il chiamante legge il quoziente soltanto nel ramo di successo.

## Che cosa insegna in più

Su errore l’output potrebbe non essere stato assegnato: un valore residuo non deve essere presentato come risultato di questa chiamata.

## Prova a cambiare il caso

Se b=0 e answer conteneva 12, è corretto stampare 12 dopo lo status di errore?

<details>
<summary>Ragionamento e risposta</summary>

No: manca un nuovo risultato valido.

</details>

## Testo dell’esercizio

```text
Consider the following code.

Class App.Math Extends %RegisteredObject
{
ClassMethod Divide(a As %Numeric, b As %Numeric, Output result As %Numeric) As %Status
{
  if b = 0 return $$$ERROR($$$GeneralError, "Division by zero")
  set result = a / b
  return $$$OK
}
}

// Caller:
set sc = ##class(App.Math).Divide(10, 3, .answer)
if $$$ISOK(sc) {
  write "Result: ", answer
} else {
  do $SYSTEM.Status.DisplayError(sc)
}

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-8-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** Result: 3.333333333333333333

The Divide method receives a\=10, b\=3. Since b is not 0, it sets result (which is the caller's answer variable via Output) to 10/3 \= 3.333333333333333333 and returns $$$OK. The caller checks $$$ISOK(sc) which is true, then writes the answer. Output parameters work with both class methods and instance methods. Note: the Output keyword is a semantic hint indicating the parameter returns a value; it does not affect runtime behavior (both ByRef and Output pass by reference identically). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_methods))

</details>
