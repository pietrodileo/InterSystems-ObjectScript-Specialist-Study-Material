# T1.3 · Q09 — Propagare il primo errore significativo

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-9-single>)

## Il passaggio che risolve l’esercizio

ValidatePerson passa il nome, poi delega l’età; lo status negativo di ValidateAge viene restituito invece di essere sostituito da OK.

## Che cosa insegna in più

Il messaggio appartiene alla causa rilevata. Ritornare sempre successo nel livello esterno renderebbe inutili le verifiche interne.

## Prova a cambiare il caso

Con nome vuoto ed età negativa, puoi assumere che siano raccolti entrambi gli errori?

<details>
<summary>Ragionamento e risposta</summary>

No: questo flusso termina al primo controllo fallito.

</details>

Visual connection: Core mechanisms, panel 3; Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following class.

Class App.Validator Extends %RegisteredObject
{
ClassMethod ValidateAge(age As %Integer) As %Status
{
  if age < 0 return $$$ERROR($$$GeneralError, "Age cannot be negative")
  if age > 150 return $$$ERROR($$$GeneralError, "Age exceeds maximum")
  return $$$OK
}

ClassMethod ValidatePerson(name As %String, age As %Integer) As %Status
{
  if name = "" return $$$ERROR($$$GeneralError, "Name is required")
  set sc = ..ValidateAge(age)
  if $$$ISERR(sc) return sc
  return $$$OK
}
}

A developer calls:

set sc = ##class(App.Validator).ValidatePerson("John", -5)
write $SYSTEM.Status.GetErrorText(sc)

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-9-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** "Age cannot be negative"

ValidatePerson is called with name \= "John" (not empty, passes first check) and age \= -5. It then calls ..ValidateAge(-5). ClassMethods CAN call other ClassMethods using the .. syntax. ValidateAge checks -5 \< 0 which is true, and returns an error status with "Age cannot be negative". This error is returned back through ValidatePerson, and GetErrorText displays the message. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GCOS_status))

</details>
