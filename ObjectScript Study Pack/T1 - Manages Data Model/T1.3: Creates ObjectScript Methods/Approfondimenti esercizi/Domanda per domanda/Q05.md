# T1.3 · Q05 — Passare l’albero di un array

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

.lines rende accessibili i sottonodi; $ORDER percorre le chiavi e il metodo legge i valori associati.

## Che cosa insegna in più

L’ordine osservato deriva dalla collazione delle chiavi, non dall’ordine con cui sono state scritte. I valori non vengono ordinati alfabeticamente.

## Prova a cambiare il caso

Se scrivi lines(3) prima di lines(1), quale viene visitato prima nell’esempio numerico?

<details>
<summary>Ragionamento e risposta</summary>

lines(1).

</details>

## Testo dell’esercizio

```text
Consider the following code.

Class App.Formatter Extends %RegisteredObject
{
ClassMethod BuildReport(ByRef lines As %String) As %String
{
  set result = ""
  set key = ""
  for {
    set key = $Order(lines(key))
    quit:key=""
    set result = result _ lines(key) _ $Char(10)
  }
  return result
}
}

// Caller:
set lines(1) = "Header"
set lines(2) = "Body"
set lines(3) = "Footer"
set report = ##class(App.Formatter).BuildReport(.lines)
write report

What does this code output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Header followed by Body followed by Footer, each on a new line

Passing an array by reference (with the dot prefix .lines) sends the entire subscripted structure to the method. Inside BuildReport, the lines parameter has subscripts lines(1), lines(2), and lines(3) accessible. The $Order loop iterates through the subscripts in order, building a string with each line separated by $Char(10) (line feed). This is the standard pattern for passing multidimensional arrays to methods in ObjectScript. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_methods))

</details>
