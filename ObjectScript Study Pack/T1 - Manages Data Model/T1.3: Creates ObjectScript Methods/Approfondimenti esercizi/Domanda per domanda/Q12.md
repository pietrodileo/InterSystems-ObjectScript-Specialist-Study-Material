# T1.3 · Q12 — Validazione a strati

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-12-single>)

## Il passaggio che risolve l’esercizio

Il padre restituisce OK, poi il figlio controlla Email. invalid-email passa il controllo non vuoto ma non contiene @.

## Che cosa insegna in più

Ogni strato aggiunge una condizione senza cancellare gli errori precedenti. La semplice presenza di @ è comunque un esempio didattico, non una validazione completa delle email.

## Prova a cambiare il caso

Se il padre fallisce, si deve continuare con le verifiche che presuppongono il suo contratto?

<details>
<summary>Ragionamento e risposta</summary>

Questo codice restituisce subito il suo errore.

## Testo dell’esercizio

```text
Consider the following class hierarchy.

Class App.Base Extends %Persistent
{
Method Validate() As %Status
{
  // Base validation logic
  return $$$OK
}
}

Class App.Extended Extends App.Base
{
Property Email As %String;

Method Validate() As %Status
{
  set sc = ##super()
  if $$$ISERR(sc) return sc
  if ..Email = "" return $$$ERROR($$$GeneralError, "Email required")
  if ..Email '[ "@" return $$$ERROR($$$GeneralError, "Invalid email")
  return $$$OK
}
}

A developer calls:

set obj = ##class(App.Extended).%New()
set obj.Email = "invalid-email"
set sc = obj.Validate()

What is the result?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-12-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: C.** An error status with "Invalid email" because ##super() returned OK, Email is not empty, but Email does not contain "@"

The execution flow is: App.Extended.Validate() calls ##super() which runs App.Base.Validate() returning $$$OK. Since sc is OK, execution continues. Email is "invalid-email" (not empty), so the first Email check passes. But "invalid-email" does not contain "@" (the \[ operator checks for substring containment), so the method returns the "Invalid email" error. This demonstrates how ##super() enables layered validation. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_methods_override))

</details>
