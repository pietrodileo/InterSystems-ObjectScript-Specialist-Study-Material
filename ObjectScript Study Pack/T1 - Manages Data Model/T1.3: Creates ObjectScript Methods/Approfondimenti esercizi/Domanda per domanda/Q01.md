# T1.3 · Q01 — Contesto di classe e di istanza

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-1-single>)

## Il passaggio che risolve l’esercizio

Area usa Radius dell’oggetto corrente; FromDiameter è un ClassMethod senza quell’istanza implicita. Entrambi possono leggere parametri di classe.

## Che cosa insegna in più

La sintassi relativa va interpretata rispetto al membro chiamato: un metodo di classe può chiamare altri metodi di classe, senza acquisire proprietà d’istanza.

## Prova a cambiare il caso

FromDiameter può creare un oggetto e impostarne Radius esplicitamente?

<details>
<summary>Ragionamento e risposta</summary>

Sì, tramite un oref esplicito anziché uno stato d’istanza implicito.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following class definition.

Class Sample.Circle Extends %RegisteredObject
{
Parameter PI = 3.14159;
Property Radius As %Integer;
ClassMethod FromDiameter(diameter As %Integer) As %Integer
{ /*Omitted*/ }
Method Area() As %Integer
{ /*Omitted*/ }
}

Which of the following is accurate about the difference between the Area and FromDiameter methods?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-1-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** The code body of Area can reference the Radius property using relative dot syntax, while this is not possible in the FromDiameter class method.

Instance methods like Area() have access to the current object context and can reference properties using the .. (double-dot) syntax (e.g., ..Radius). Class methods like FromDiameter() have no object context and therefore cannot use .. to access instance properties. However, both instance and class methods CAN access class parameters using ..#ParamName (option A is incorrect). Class methods do not require an instance to call (option C is reversed). Instance methods can call class methods (option D is incorrect). (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_methods))

</details>
