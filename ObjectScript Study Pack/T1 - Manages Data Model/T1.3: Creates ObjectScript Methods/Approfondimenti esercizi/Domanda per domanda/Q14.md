# T1.3 · Q14 — Tipo compatibile e riferimento esistente

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-14-single>)

## Il passaggio che risolve l’esercizio

%IsA accetta la classe e le sottoclassi; un confronto con il solo nome rifiuterebbe Patient pur essendo Person.

## Che cosa insegna in più

Prima di chiamare %IsA su input non fidato, controlla che sia un oref valido: compatibilità del tipo e validità del riferimento sono verifiche distinte.

## Prova a cambiare il caso

Un valore vuoto può essere interrogato come oggetto solo perché il parametro dichiara Person?

<details>
<summary>Ragionamento e risposta</summary>

Non fare affidamento sulla sola dichiarazione: valida il riferimento.

</details>

Visual connection: Core mechanisms, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following classes.

Class Sample.Person Extends %Persistent
{
// Omitted
}

Class Sample.Patient Extends Sample.Person
{
// Omitted
}

You are writing code that accepts an object reference and need to verify the caller passed an instance of Sample.Person or a subclass.

Which of the following code blocks correctly accomplishes that?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-14-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** ```text
ClassMethod ProcessPatient(oref As Sample.Person)
{
  if 'oref.%IsA("Sample.Person") return "Wrong Class"
}
```

The %IsA() method checks whether an object is an instance of a specified class OR any of its subclasses. Passing a Sample.Patient instance would return true for %IsA("Sample.Person") because Patient extends Person. Option A fails because %ClassName() returns only the short class name ("Person") without the package, and it would reject valid subclass instances. Option C uses $CLASSNAME which is not a standard ObjectScript function. Option D uses %TypeOf() which does not exist. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_model_inheritance_extents))

</details>
