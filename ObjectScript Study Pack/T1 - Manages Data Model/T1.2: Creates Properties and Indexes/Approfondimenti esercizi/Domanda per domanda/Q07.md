# T1.2 · Q07 — Aprire tramite indice univoco

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-7-single>)

## Il passaggio che risolve l’esercizio

EmailIdxOpen restituisce un oggetto, non lo status suggerito dal nome della variabile sc nel chiamante.

## Che cosa insegna in più

Usare nomi coerenti con i tipi di ritorno riduce errori: account per l’oref e sc2 per lo status di uscita. Il SET non cambia il tipo del risultato.

## Prova a cambiare il caso

Dopo set sc=EmailIdxOpen(...), puoi usare $$$ISOK(sc) per valutare l’apertura?

<details>
<summary>Ragionamento e risposta</summary>

Non è il controllo appropriato per un oref.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following class.

Class App.Account Extends %Persistent
{
Property Email As %String(MAXLEN = 250);
Index EmailIdx On Email [ Unique ];
}

The following records exist:
  ID 1: Email = "alice@example.com"
  ID 2: Email = "bob@example.com"

A developer runs:

set sc = ##class(App.Account).EmailIdxOpen("alice@example.com", , .sc2)

What does EmailIdxOpen() return?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-7-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** An oref pointing to the App.Account object with Email \= "alice@example.com"

When a unique index is defined, the system generates helper methods including \<IndexName\>Open() which opens the object by the unique index value instead of the ID. EmailIdxOpen("alice@example.com") looks up the unique index, finds the corresponding ID (1), and returns the fully loaded oref. Other generated methods include EmailIdxExists() to check existence and EmailIdxDelete() to delete by the indexed value. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_defpersobj))

</details>
