# T1.4 · Q14 — Serializzazione del grafo annidato

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-14-single>)

## Il passaggio che risolve l’esercizio

items contiene riferimenti a due oggetti; %ToJSON visita anche questi oggetti e produce la struttura completa.

## Che cosa insegna in più

Il total impostato manualmente è un dato separato: la serializzazione non ricalcola quantità per prezzo né garantisce la coerenza del totale.

## Prova a cambiare il caso

Se qty cambia dopo aver assegnato total, il totale si corregge da solo?

<details>
<summary>Ragionamento e risposta</summary>

No: serve una regola applicativa di ricalcolo.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 4. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer creates a nested JSON structure.

set order = {}
set order.orderId = "ORD-001"
set order.items = []
set item1 = {"sku": "A100", "qty": 2, "price": 29.99}
set item2 = {"sku": "B200", "qty": 1, "price": 49.99}
do order.items.%Push(item1)
do order.items.%Push(item2)
set order.total = 109.97
write order.%ToJSON()

Which of the following represents the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-14-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** {"orderId":"ORD-001","items":\[{"sku":"A100","qty":2,"price":29.99},{"sku":"B200","qty":1,"price":49.99}\],"total":109.97}

%DynamicArrays can hold any type of value including nested %DynamicObjects. When item1 and item2 are pushed into the items array, they maintain their full structure. %ToJSON() recursively serializes the entire object graph, producing the complete nested JSON. The dot syntax (order.items) returns a reference to the same array object, so %Push operations on it affect the array inside the order object. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GJSON_create))

</details>
