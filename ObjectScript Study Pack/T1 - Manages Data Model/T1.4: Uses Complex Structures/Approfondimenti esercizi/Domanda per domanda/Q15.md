# T1.4 · Q15 — Testo e terminatori di riga

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-15-single>)

## Il passaggio che risolve l’esercizio

WriteLine aggiunge il terminatore alla stringa vuota dell’esempio; Write aggiunge soltanto i caratteri forniti.

## Che cosa insegna in più

Il risultato visivo può essere uguale mentre la rappresentazione del newline varia per piattaforma o configurazione. Consideralo negli scambi di file.

## Prova a cambiare il caso

Per dati binari arbitrari, useresti FileCharacter confidando che i byte restino equivalenti?

<details>
<summary>Ragionamento e risposta</summary>

No: scegli uno stream binario.

</details>

Visual connection: Core mechanisms, panel 3. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following code that uses %Stream.FileCharacter.

set stream = ##class(%Stream.FileCharacter).%New()
set stream.Filename = "/tmp/output.txt"
do stream.Write("Hello, World!")
do stream.WriteLine("")
do stream.Write("Second line.")
set sc = stream.%Save()

After this code runs, what does the file /tmp/output.txt contain?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-15-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** Hello, World! followed by a newline, then Second line.

%Stream.FileCharacter writes data to a file on the filesystem. Write() appends text and WriteLine() appends text plus a platform-appropriate line terminator. The content accumulates: "Hello, World!" \+ newline (from WriteLine) \+ "Second line.". When %Save() is called, the buffered data is flushed to the file. Unlike %Stream.GlobalCharacter, file-based streams can be saved independently without requiring a persistent parent object. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_propstream))

</details>
