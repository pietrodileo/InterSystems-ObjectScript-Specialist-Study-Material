# T1.4 · Q03 — Valore e tipo nella serializzazione

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-3-single>)

## Il passaggio che risolve l’esercizio

%Set con null o boolean controlla la rappresentazione; error diventa null e verified diventa true nello scenario.

## Che cosa insegna in più

Una stringa che contiene true non è il booleano true. Il consumatore JSON può attribuire loro significati diversi.

## Prova a cambiare il caso

Che differenza vedi tra verified="true" e verified=true nel JSON?

<details>
<summary>Ragionamento e risposta</summary>

Il primo è testo, il secondo è un valore booleano.

</details>

## Testo dell’esercizio

```text
A developer needs to build a JSON response with explicit null and boolean values.

set resp = {}
do resp.%Set("status", "success")
do resp.%Set("count", 42)
do resp.%Set("error", "", "null")
do resp.%Set("verified", 1, "boolean")
write resp.%ToJSON()

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-3-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** {"status":"success","count":42,"error":null,"verified":true}

The three-argument form of %Set(key, value, type) controls how values are serialized to JSON. With type "null", the value is output as the JSON keyword null regardless of the actual value passed. With type "boolean", a truthy ObjectScript value (1) becomes JSON true and a falsy value (0) becomes JSON false. Without the type argument, numbers stay as JSON numbers and strings stay as JSON strings. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GJSON_create))

</details>
