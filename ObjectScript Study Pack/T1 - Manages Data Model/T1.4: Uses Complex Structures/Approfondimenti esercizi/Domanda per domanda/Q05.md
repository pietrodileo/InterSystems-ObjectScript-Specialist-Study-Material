# T1.4 · Q05 — Push e Pop con stato intermedio

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

Dopo tre inserimenti, Pop rimuove blue; il nuovo Push mette yellow in coda. La dimensione finale resta tre.

## Che cosa insegna in più

Per capire una sequenza mutabile annota il contenuto dopo ogni operazione, non soltanto il numero di chiamate.

## Prova a cambiare il caso

Dopo un altro Pop quale valore ottieni?

<details>
<summary>Ragionamento e risposta</summary>

yellow, l’ultimo elemento rimasto in coda.

</details>

Visual connection: Core mechanisms, panel 2; Further insights, panel 1. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
A developer writes the following code to build a %DynamicArray.

set colors = []
do colors.%Push("red")
do colors.%Push("green")
do colors.%Push("blue")
set removed = colors.%Pop()
do colors.%Push("yellow")
write colors.%Size(), ": "
write colors.%ToJSON()

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** 3: \["red","green","yellow"\]

Starting with an empty array, %Push adds "red" (index 0), "green" (index 1), "blue" (index 2). Then %Pop() removes and returns the last element ("blue"), leaving \["red", "green"\]. Then %Push("yellow") adds "yellow" at the end, resulting in \["red", "green", "yellow"\]. %Size() returns 3 because there are 3 elements. The output is 3: \["red","green","yellow"\]. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GJSON_create))

</details>
