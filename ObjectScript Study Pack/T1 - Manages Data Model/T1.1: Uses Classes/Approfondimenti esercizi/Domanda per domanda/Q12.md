# T1.1 · Q12 — Oggetto in memoria e API persistente

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-12-single>)

## Il passaggio che risolve l’esercizio

Counter eredita da %RegisteredObject: Increment funziona sullo stato in memoria, ma ciò non gli conferisce %Save.

## Che cosa insegna in più

Non ogni oggetto istanziabile è un record. La possibilità di serializzare contenuti non equivale al contratto di una classe %Persistent.

## Prova a cambiare il caso

Per un contatore usato soltanto durante una richiesta serve una tabella?

<details>
<summary>Ragionamento e risposta</summary>

No, se la durata richiesta coincide con quella dell’istanza in memoria.

</details>

## Testo dell’esercizio

```text
Consider the following class.

Class App.Counter Extends %RegisteredObject
{
Property Count As %Integer [ InitialExpression = 0 ];

Method Increment() As %Integer
{
  set ..Count = ..Count + 1
  return ..Count
}
}

A developer runs:

set c = ##class(App.Counter).%New()
write c.Increment(), " "
write c.Increment(), " "
set sc = c.%Save()

What happens when c.%Save() is called?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-12-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** A runtime error occurs because %RegisteredObject does not have a %Save() method

%RegisteredObject does not define a %Save() method. Only %Persistent classes (and %SerialObject for embedded serialization) provide %Save(). Attempting to call %Save() on a %RegisteredObject instance results in a \<METHOD DOES NOT EXIST\> error at runtime. The object exists only in process memory and cannot be persisted. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_objapi))

</details>
