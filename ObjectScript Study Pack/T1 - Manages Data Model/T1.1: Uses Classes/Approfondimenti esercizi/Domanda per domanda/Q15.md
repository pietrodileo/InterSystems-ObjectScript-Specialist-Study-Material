# T1.1 · Q15 — Override e salvataggio ignorato

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-15-single>)

## Il passaggio che risolve l’esercizio

Log della sottoclasse sostituisce il metodo ereditato. Il messaggio viene assegnato e il codice tenta %Save.

## Che cosa insegna in più

Il frammento usa DO per un metodo che produce uno status: manca la gestione esplicita dell’esito del salvataggio. L’avvenuta chiamata non prova il successo dell’audit.

## Prova a cambiare il caso

Quale risultato controlleresti prima di dichiarare che il log è persistito?

<details>
<summary>Ragionamento e risposta</summary>

Lo status di %Save, propagandolo al chiamante se necessario.

</details>

## Testo dell’esercizio

```text
Consider the following two classes.

Class App.Logger Extends %RegisteredObject
{
Method Log(msg As %String)
{
  write $ZDT($H, 3), ": ", msg, !
}
}

Class App.AuditLogger Extends (%Persistent, App.Logger)
{
Property LogEntry As %String(MAXLEN = 500);

Method Log(msg As %String)
{
  set ..LogEntry = $ZDT($H, 3) _ ": " _ msg
  do ..%Save()
}
}

A developer writes:

set logger = ##class(App.AuditLogger).%New()
do logger.Log("System started")

What happens when Log() is called?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-15-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** The Log() method from App.AuditLogger executes, saving the message to the database

When a subclass defines a method with the same name as a parent class method, the subclass method overrides the parent. Since the object is an instance of App.AuditLogger, its own Log() method is called, which sets the LogEntry property and saves the object to the database. If the developer wanted to also call the parent's Log(), they would use ##super(msg) inside the overriding method. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_methods_override))

</details>
