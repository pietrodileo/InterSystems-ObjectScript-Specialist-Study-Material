# T1.4 · Q12 — Rimuovere non equivale a oscurare

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-12-single>)

## Il passaggio che risolve l’esercizio

%Remove elimina password dalla struttura serializzata, anziché sostituirla con stringa vuota o null.

## Che cosa insegna in più

La modifica riguarda quell’oggetto in memoria. Non dimostra che la password sia stata rimossa da log precedenti, altre copie o persistenza.

## Prova a cambiare il caso

Se user ha un alias prima della rimozione, l’alias vede ancora la proprietà?

<details>
<summary>Ragionamento e risposta</summary>

No, se punta allo stesso oggetto modificato.

</details>

## Testo dell’esercizio

```text
A developer needs to remove a property from a %DynamicObject before sending it as a JSON response.

set user = {"id": 1, "name": "Alice", "password": "secret123", "role": "admin"}
do user.%Remove("password")
write user.%ToJSON()

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-12-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** {"id":1,"name":"Alice","role":"admin"}

%Remove() completely removes the specified property from the %DynamicObject. After removal, the property no longer exists in the object \-- it is not set to null or empty string, it is entirely gone. The %ToJSON() output excludes the removed property, producing a clean JSON object with only the remaining properties. This is useful for sanitizing data before sending API responses. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GJSON_create))

</details>
