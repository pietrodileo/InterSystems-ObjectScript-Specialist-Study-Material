# T1.4 · Q02 — Indici JSON a base zero

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-2-single>)

## Il passaggio che risolve l’esercizio

patients.%Get(1) seleziona Bob perché Alice occupa la posizione zero.

## Che cosa insegna in più

Non trasferire gli indici delle liste ObjectScript ai DynamicArray: le due strutture hanno convenzioni differenti.

## Prova a cambiare il caso

Con tre pazienti, quali sono gli indici validi per visitarli tutti?

<details>
<summary>Ragionamento e risposta</summary>

0, 1 e 2.

</details>

Visual connection: Core mechanisms, panel 2. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following code that processes a JSON API response.

set jsonStr = "{""patients"":[{""name"":""Alice"",""age"":30},{""name"":""Bob"",""age"":45}]}"
set response = ##class(%DynamicObject).%FromJSON(jsonStr)
set patients = response.patients
write patients.%Get(1).name

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-2-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** Bob

%DynamicArray is zero-indexed. %Get(0) returns the first element (Alice's object) and %Get(1) returns the second element (Bob's object). Then .name accesses the "name" property of that object, returning "Bob". The %FromJSON method correctly parses nested JSON structures into nested %DynamicObject and %DynamicArray instances. Property access can be chained on the returned objects. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GJSON_create))

</details>
