# T1.4 · Q07 — Presente ma nullo

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-7-single>)

## Il passaggio che risolve l’esercizio

address esiste e ha tipo null; phone non esiste. Un valore mancante e uno esplicitamente nullo trasmettono informazioni diverse.

## Che cosa insegna in più

Questa distinzione è decisiva negli aggiornamenti parziali: campo omesso può significare non modificare, null può significare cancellare il valore, secondo il contratto API.

## Prova a cambiare il caso

Sostituendo address:null con la rimozione della proprietà, %IsDefined restituisce ancora 1?

<details>
<summary>Ragionamento e risposta</summary>

No.

## Testo dell’esercizio

```text
A developer needs to check whether a JSON property exists and determine its type.

set data = {"name": "Alice", "score": 95, "address": null}
write data.%IsDefined("name"), " "
write data.%IsDefined("phone"), " "
write data.%GetTypeOf("address")

What is the output?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-7-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: A.** 1 0 null

%IsDefined() returns 1 if the property exists in the object and 0 if it does not. "name" exists (returns 1), "phone" does not exist (returns 0). %GetTypeOf() returns a string describing the JSON type of the value: "null" for JSON null, "string" for strings, "number" for numbers, "boolean" for booleans, "object" for nested objects, "array" for arrays, and "unassigned" for properties that do not exist. Since "address" is explicitly set to null, its type is "null". (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GJSON_create))

</details>
