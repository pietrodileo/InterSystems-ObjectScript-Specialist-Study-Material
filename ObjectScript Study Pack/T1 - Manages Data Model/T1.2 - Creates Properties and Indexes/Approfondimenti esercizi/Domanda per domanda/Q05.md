# T1.2 · Q05 — Calculated non significa formula inventata

[Tutte le domande](README.md) · [Approfondimenti del capitolo](../README.md) · [Domanda originale](<../../quiz.md#question-5-single>)

## Il passaggio che risolve l’esercizio

FullName non è memorizzato: serve un accessor o un meccanismo di calcolo coerente con i keyword scelti. Il nome della proprietà non fornisce la formula.

## Che cosa insegna in più

Una proprietà virtuale è un’interfaccia: chi la legge deve ottenere il risultato del calcolo, senza trattarla come una copia da aggiornare manualmente.

## Prova a cambiare il caso

Se LastName cambia, FullName virtuale deve attendere una migrazione dei record?

<details>
<summary>Ragionamento e risposta</summary>

No: dipende dal calcolo eseguito in lettura.

</details>

Visual connection: Core mechanisms, panel 3; Further insights, panel 3. See the [English diagrams and panel explanations](../tavole-esercizi.md).

## Testo dell’esercizio

```text
Consider the following class.

Class App.Person Extends %Persistent
{
Property FirstName As %String(MAXLEN = 100);
Property LastName As %String(MAXLEN = 100);
Property FullName As %String [ Calculated ];
}

A developer writes:

set p = ##class(App.Person).%OpenId(1)
write p.FullName

The output is empty. What is the most likely reason?
```

[Apri il quiz con tutte le opzioni](<../../quiz.md#question-5-single>).

<details>
<summary>Risposta e spiegazione originali della fonte (inglese)</summary>

**Correct answer: B.** The Calculated keyword means the value is never stored; a custom Get accessor method (FullNameGet) must be defined for ObjectScript access

The Calculated keyword means the property value is never stored on disk. When reading a Calculated property in ObjectScript, it invokes the Get accessor method (FullNameGet). If no FullNameGet() method is defined, the property returns empty string. The fix is to add: Method FullNameGet() As %String { return ..FirstName \_ " " \_ ..LastName }. Note: if SqlComputeCode is also defined alongside Calculated, IRIS auto-generates a Get method from it — but without SqlComputeCode, you must provide your own. (Reference: [Reference](https://docs.intersystems.com/irislatest/csp/docbook/DocBook.UI.Page.cls?KEY=GOBJ_propmethods))

</details>
